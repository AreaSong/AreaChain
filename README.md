# AreaChain

AreaChain 是专为 macOS 打造的高效个人任务看板与习惯打卡助手：既是菜单栏上随手唤出、支持自然语言输入的轻量便签本，也是支持多维规划与批量管理的三栏大屏工作台。数据完全存放于本机，无广告、无多余依赖，守护你的纯粹与专注。

## 核心特性

- **菜单栏极速输入与智能解析**：
  - 顶栏常驻书本印章图标与「今」字标识，未完成待办角标一目了然。
  - 支持 **自然语言智能解析**（NLP）：自动识别中文时间（如 `下午3点半`、`15:30`）、优先级指令（`!p1`~`!p4`、`!重要且紧急`）、主题标签（`#工作`）与多行长文本备注切分。
  - 默认 **⌘⇧A** 随时唤出浮层，**⌘⇧V** 一键抓取剪贴板转为今日待办或图片附件。
- **三栏大屏工作台与任务检查器**：
  - 全新三栏工作台（`MainSplitWorkspaceView`）：左侧视图与项目标签树导航，中栏沉浸清单，右侧全功能任务检查器抽屉（`TaskDetailDrawer`）。
  - 底部浮动批量操作栏（`BatchActionBar`）：多选待办一键批量改期（今天/明天）、批量完成、绑定项目/标签或移入废纸篓。
- **习惯打卡与连续天数激励**：
  - 常驻习惯融入今日清单统一打卡；智能推算连击天数与历史纪录，点亮 `🔥 N` 火焰勋章。
  - 智能桥接非排定日（如工作日设定的周末）与「今天跳过」，休假不破连击纪录。
  - 顶部圆形进度仪表（`TodayProgressCard`）实时呈现今日达成率。
- **子任务拆解与长文本详细备注**：
  - 待办支持多级子任务拆解，行内展现 `2/3` 胶囊进度并支持快速展开折叠，级联完成与软删除。
  - 支持多行详细长备注（`notes`），列表行提取首行轻量摘要预览，抽屉内嵌富文本编辑。
- **多维看板矩阵**：
  - **日历月视图**：月网格未完成数量一览，支持跨日拖拽灵活改期。
  - **四象限矩阵**：艾森豪威尔重要/紧急四宫格，拖拽调整事务优先级。
  - **安排甘特图**：当月轻量时间轴，直观展现任务工期与习惯周期。
  - **日记长廊**：按日回溯每日一句碎碎念，支持图文附件。
  - **附件中心、全局搜索与回收站**：集中管理多媒体素材，跨日期模糊搜索，全对象软删除安全防误删。
- **本地私密与高可靠存储**：
  - 基于 SwiftData 构建 8 张核心数据表，二进制数据零泄露。
  - 支持完整 JSON 快照导入与导出；可选单向同步临时待办至 macOS 专用日历。

## 构建与运行

需要 macOS 14.0+ 与 Xcode 16.0+。

直接使用根目录编译脚本：

```bash
# 编译 Debug 版、安装到 /Applications 并启动
./scripts/build.sh

# 仅编译
./scripts/build.sh build

# 仅安装已有构建产物
./scripts/build.sh install

# 执行全量单元测试
./scripts/build.sh test
```

也可以直接通过 Xcode 打开工程：`open AreaChain.xcodeproj`。

## 目录结构

```text
AreaChain/          macOS 应用主源码（按层划分，详见 docs/architecture.md）
AreaChainTests/     单元测试套件，严格镜像 Domain 与 Services 结构
scripts/            编译、构建、安装与测试自动化脚本
docs/               产品需求、功能清单、架构方案与用户指南
AreaChain.xcodeproj Xcode 项目工程文件
```

## 明确不做 (边界声明)

不做外部繁重会议日程抓取，不搞耗电的后台剪贴板轮询，不设立云端登录账户与外部推送，不添加倒计时番茄钟，专注于克制、快速、本地私密的个人效率体验。
