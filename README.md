# AreaChain

AreaChain 是专为 macOS 打造的个人任务看板与习惯打卡助手：菜单栏随手唤出、支持自然语言输入的轻量便签本，加上一扇三栏工作台做规划与批量管理。数据完全存放于本机，无广告、无账号。

## 核心特性

- **菜单栏极速输入与智能解析**：
  - 顶栏书本印章与「今」字，未完成时显示数字角标。
  - **NLP**（浮层与工作台今日输入）：中文/数字时间（如 `下午3点半`、`下午3点开会`、`15:30`、`@18:00`）、优先级（`!p1`~`!p4`、`!重要且紧急`）、第一个 `#标签`、多行备注切分。不解析「明天」等日期词；「修复3点问题」不当时刻。
  - 默认 **⌘⇧A** 唤起浮层，**⌘⇧V** 单次读取剪贴板：文字整段当标题（不跑 NLP；同时有图也不挂图），仅图片才挂为附件。
- **三栏工作台与任务检查器**：
  - `MainSplitWorkspaceView`：左侧聚焦/看板/记录/项目/标签/系统，中栏清单，右侧 `TaskDetailDrawer`。日历、四象限、甘特、手记等均在同一窗口切 tab。
  - 批量操作在**项目/标签专属清单**（⌘ 多选）：改期、完成、项目、标签、进回收站。今日主清单是单选。
  - 清单键盘：↑↓ 移动、Space 勾选、Return 开检查器、E 改标题、Delete 待办或习惯进回收站。Esc：编辑中先退出输入（抽屉标题回滚），否则先关检查器再回输入框。
- **习惯打卡与连续天数**：
  - 习惯与待办同一张今日清单；`🔥 N` 当前连击，抽屉另有历史最高。
  - 非排定日与「今天跳过」桥接，不破连击。工作台进度环只统计临时待办。
- **一层子任务与纯文本备注**：
  - 行内 `2/3` 胶囊，可展开勾选；勾完父任务会级联完成子任务。
  - 多行 `notes`，行上显示首行预览；抽屉是纯文本，不是富文本。
- **多维看板**：
  - **日历**：月网格未完成数，临时待办可拖到另一天。
  - **四象限**：重要/紧急四宫格，只列该日未完成，拖拽改优先级。
  - **安排**：当月未完成临时待办的单日色块，拖到另一天改期（不是拉伸工期）。
  - **灵感手记**：长期记录本。三个分类（密码 / 小巧思 / 日记）可在写入时或成卡后打标；关键字自动归类；密码模糊与免明文复制（模糊时不能编辑、不能选图）。
  - **附件、搜索、回收站**：集中看活父项的图；搜标题/习惯名/手记正文；软删可恢复（孤儿附件不能单独恢复）。
- **本地存储**：
  - SwiftData 8 张表。JSON 快照可导入导出（含手记标签与置顶；图片二进制不含）。
  - 可选把未完成临时待办同步到本机「AreaChain」日历（推+拉，不收其它日历会议）。

## 构建与运行

需要 macOS 14.0+ 与 Xcode 16.0+。

```bash
# 编译 Debug 版、安装到 /Applications 并启动
./scripts/build.sh

# 仅编译
./scripts/build.sh build

# 仅安装已有构建产物
./scripts/build.sh install

# 执行全量单元测试
./scripts/build.sh test
```

也可以：`open AreaChain.xcodeproj`。

## 目录结构

```text
AreaChain/          macOS 应用主源码（分层见 docs/architecture.md）
AreaChainTests/     单元测试，镜像 Domain 与 Services
scripts/            编译、安装与测试脚本
docs/               产品、功能、架构、用法
AreaChain.xcodeproj
```

## 明确不做

不做外部会议收割，不后台轮询剪贴板，不自建云端账号（设置里 iCloud 开关是占位），不加番茄钟，不把甘特做成多日工期或前置依赖。
