# AreaChain

AreaChain 是专为 macOS 打造的个人任务看板与习惯打卡助手：菜单栏随手唤出、支持自然语言输入的轻量便签本，加上一扇三栏工作台做规划与批量管理。数据完全存放于本机，无广告、无账号。

## 核心特性

- **菜单栏极速输入与智能解析**：
  - 菜单栏只保留固定占位的书本图标：内嵌小点表示尚有事项，内嵌勾号表示今日已处理完，暂无安排时为普通图标。准确数量在悬停提示与浮层中查看，不再预留数字区。
  - **NLP**（待办与习惯的新增、标题编辑，覆盖浮层、工作台、日历及标签页）：中文/数字时间（如 `下午3点半`、`下午3点开会`、`15:30`、`@18:00`）、优先级（`!p1`~`!p4`、`!重要且紧急`；`!p4` 预览为「其余」）、多个 `#标签`（包含备注各行）、多行备注切分。不解析「明天」等日期词。「修复3点问题」不当时刻。没有项目。
  - 默认 **⌘⇧A** 唤起浮层，**⌘⇧V** 单次读取剪贴板：文字整段当标题并识别标签（保留原文，不解析时间和优先级；同时有图也不挂图），仅图片才挂为附件。
  - 浮层底栏提供语法搜索（**⌘F**，支持 `#标签`、`!p1`～`!p4`、`@15:30`），跨日期查找任务、子任务、习惯和手记；筛选展开时整条底栏原位换成标签，收起后恢复搜索、工作台与更多入口。
- **三栏工作台与任务检查器**：
  - `MainSplitWorkspaceView`：左侧导航、中栏清单、右侧 `TaskDetailDrawer`。搜索在顶部，不作为侧栏一级入口。事项含今日、待处理（页内逾期/即将）和全部事项。重复事项从今日页管理，没有独立侧栏入口。日历、四象限、安排、灵感手记等均在同一窗口切 tab。设置只含偏好。Dashboard、活动记录和热力图已接通。隐私与解锁、数据与备份已是独立页面。浅深色、最小窗口和原生走查尚未做，阶段八未开始。
  - 日清单与标签清单支持单击单选、Shift 点击连续选择、⌘ 点击增减选择。圆圈只切换当前任务，行中间双击编辑，右侧 ⋯ 打开菜单。批量操作在标签专属清单、待处理和全部事项：改期、完成、打标签、移除标签、进回收站。重复事项批量打卡使用每一行自己的检查日。没有项目。
  - 清单键盘：↑↓ 移动、Space 勾选、Return 开检查器、E 改标题、Delete 待办或习惯进回收站。Esc：编辑中先退出输入（抽屉标题回滚），否则先关检查器再回输入框。
- **物理级打卡微动效与沉底体验**：
  - 待办与习惯勾选时提供细腻物理级交互：复选框基于贝塞尔路径实时生长绘制对勾（Path Trim 动画），配合微弹性缩放与触控板触感反馈（Haptic）；任务标题从左向右平滑滑出删除线并柔和变淡。
  - **0.4 秒防反悔驻留**：打勾后原位停留 0.4 秒，提供明确完成感且支持原地秒级撤回；到期后以弹簧曲线柔和折叠沉底收纳至「已完成」区域。
  - **全局动态联动**：顶部「今天还剩 N 项」与习惯连击徽章「🔥 N」支持数字滚轮翻滚过渡（`.numericText`），全清时状态点平滑变形为勾号。无障碍支持系统「减弱动态效果」（Reduce Motion）。
- **习惯打卡与连续天数**：
  - 习惯与待办同一张今日清单；`🔥 N` 当前连击，抽屉另有历史最高。
  - 非排定日与「今天跳过」桥接，不破连击。工作台进度环只统计当天的一次性事项；角标仍含当天未完成的重复事项。
- **一层子任务与纯文本备注**：
  - 行内 `2/3` 胶囊，可展开勾选；子任务有独立标签，可搜索并在标签页查看；勾完父任务会级联完成子任务。
  - 多行 `notes`，行上显示首行预览；抽屉是纯文本，不是富文本。
- **多维看板**：
  - **日历**：月网格未完成数，临时待办可拖到另一天。
  - **四象限**：宫格是「重要且紧急 / 重要 / 紧急 / 其余」，只列该日未完成，拖拽改优先级。
  - **安排**：当月未完成临时待办的单日色块，⌘ 点选增减多选、Shift 连选；拖动或 ←/→ 整体改期，保留日期间隔（不是拉伸工期）。拖动时只显示一份预览，Esc 取消。
  - **灵感手记**：长期记录本，支持标签、自动分类、置顶和独立小窗。在「隐私与解锁」中可按标签加密正文及图片，系统验证与独立主密码可单选或同时启用；锁定、失焦和搜索共用隐私规则。菜单栏保留固定输入区和两行摘要，小窗支持显式保存、关闭前确认和编辑冲突保护。
  - **附件、搜索、回收站**：集中看活父项的图；搜任务/子任务/习惯及手记；软删可恢复（孤儿附件不能单独恢复）。
- **本地存储**：
  - SwiftData 7 张表：重复事项、打卡、一次性事项、子任务、手记、标签、附件。没有项目表。旧 JSON 里的项目字段会被忽略，不会转成标签。普通 JSON 快照排除私密及旧密码遮罩手记，不含图片二进制；独立口令的加密备份包含全部记录与图片，可在新私密锁下恢复。
  - 可选把未完成临时待办同步到本机「AreaChain」日历（基于上次成功状态核对推拉，冲突保留，不收其它日历会议）。

## 构建与运行

需要 macOS 14.0+ 与 Xcode 16.0+；构建检查脚本另需 Python 3.9+（仅使用标准库）。

仓库默认是不绑定个人账号的本机临时签名。指纹／系统密码解锁须使用自己的开发签名配置，见 [本机构建与系统解锁签名](docs/signing.md)。开发签名的 Release 包不等于已公证的正式发行包。

```bash
# 仅编译并检查 Debug，不安装、不启动
./scripts/build.sh

# 检查当前签名配置
./scripts/build.sh check-signing

# 生成并验签 Release 候选包，不覆盖现用应用
./scripts/build.sh release

# 查看已安装版本和签名状态
./scripts/app.sh status

# 只预览已有 Debug 的安装检查，不安装、不启动
./scripts/install.sh --dry-run

# 执行全量单元测试
./scripts/build.sh test

# 只读检查工作流引用、Domain 导入与项目技能共享边界；不构建/启动应用
python3 -B scripts/check_workflow.py
```

构建与安装是独立入口。完成数据备份并正常退出应用后，运行 `./scripts/install.sh` 会增量构建当前 Debug、验签、请求确认，再安装并启动。开发中用 `./scripts/install.sh --yes` 装上工作区里的最新代码。`--no-build` 使用已有 Debug，`--no-open` 安装后不启动，`--release` 才改为整包优化的 Release。

`./scripts/uninstall.sh`（或 `./scripts/app.sh delete`）确认后只将应用移到可恢复目录，保留全部数据、私密锁、钥匙串和证书；可先加 `--dry-run` 预览。脚本不会强制结束应用，不自动切换签名身份，也不提供清空数据命令。完整命令、回退与限制见 [安装与回退门禁](docs/signing.md#安装与回退门禁)。

也可以：`open AreaChain.xcodeproj`。

## 目录结构

```text
AreaChain/          macOS 应用主源码（分层见 docs/architecture.md）
AreaChainTests/     单元测试，镜像 Domain 与 Services
scripts/            构建、签名核验、应用管理与测试脚本
Config/             通用签名配置与个人配置示例
docs/               产品、功能、架构、用法
skill-routing.md    项目级技能选择与交付闭环
.agents/skills/     可共享的 AreaChain 项目技能
AreaChain.xcodeproj
```

## 明确不做

不做外部会议收割，不后台轮询剪贴板，不自建云端账号（设置里 iCloud 开关会写入偏好，但不改本地库），不加番茄钟，不把甘特做成多日工期或前置依赖。
