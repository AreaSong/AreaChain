# 使用说明

AreaChain 既是菜单栏上的轻量随手待办本，也是支持沉浸规划的三栏大屏工作台。

## 1. 启动与呼出

1. **菜单栏图标**：点屏幕顶端菜单栏的 **书本印章图标 +「今」**（英文界面为 `T`）打开主浮层；有未完成时显示数字（如 `今3`），数字含未打卡习惯。若图标被系统挤出，可点菜单栏最左侧的 `«` 展开。
2. **全局热键（浮层）**：默认 **⌘⇧A** 呼出或收起浮层，在「设置 → 启动」中可重录。热键必须包含 ⌘ / ⌥ / ⌃ 之一，纯 Shift 无效。
3. **剪贴板捕获**：默认 **⌘⇧V** 单次读取剪贴板。有文字则**整段当作今天一条待办的标题**（不解析时间/标签/优先级）；仅图片则建待办并挂附件；为空不触发。粘贴热键不能与唤起热键相同。
4. **三栏工作台**：浮层标题栏的展开按钮，或底栏 **工作台**，打开同一扇工作台窗口。日历、手记、四象限、甘特、附件、搜索、回收站都在工作台左侧切换。侧栏 **系统 → 设置** 也是同一窗口；macOS **⌘,** 仍会打开系统 Settings 场景（同一套设置页）。
5. **浮层底栏**：显示当前唤起热键；可退出应用。

浮层分「待办 / 手记」两个页签。平时无 Dock 图标；打开工作台后 Dock 会出现，关掉工作台再消失。

> **提示**：关浮层后再开，捕获框里未提交的草稿会保留。这只保证浮层，不保证工作台输入框。

## 2. 极速输入与智能解析

### 浮层

- **回车** 或点 **添加**：保存为今天的临时待办（走 NLP）。写出时刻时会申请通知权限。
- **⌘回车** 或点 **手记**：记入灵感手记（解析 `#标签` 并按关键字自动打上密码/小巧思/日记），然后跳到浮层手记页。
- **Shift+Enter**：插入换行，便于多行备注。捕获框为空时再按 **↓**，焦点进入清单第一项。
- **Esc**：捕获框失焦。

### 工作台今日页

- 顶部 composer **回车** 添加今天的临时待办（走 NLP）。带时刻时会申请通知权限。
- 没有手记按钮，也没有 ⌘Return 记手记；⌘Return 也不会当成回车新建待办。手记请到侧栏「灵感手记」，或用浮层 ⌘Return。
- 日历页、项目/标签专属清单里的添加是纯标题，不跑 NLP。

### 自然语言解析示例

仅浮层与工作台今日 composer 添加待办时生效。输入时会出现时间 / 标签 / 优先级胶囊预览。

| 输入格式示例 | 自动解析结果 |
|---|---|
| `下午3点半 团队周会` | 标题「团队周会」，提醒 **15:30**。 |
| `@18:00 去健身房跑步 #运动` | 标题「去健身房跑步」，时刻 **18:00**，标签「运动」。 |
| `!p1 提交核心技术方案` | 标题「提交核心技术方案」，**重要且紧急**。 |
| `!重要 整理下季度规划` | 标题「整理下季度规划」，标为 **重要**。 |
| `中午12点和产品经理吃午饭 !p2 #工作` | 时刻 **12:00**，优先级 **重要**，标签「工作」，标题「和产品经理吃午饭」。 |

**不会发生的事**：写「明天」不会改到明天，`dayKey` 仍是今天，「明天」留在标题里。只取第一个 `#标签`。不解析项目名。`!p4` 会预览为「不重要不紧急」。

### 多行长备注

浮层用 Shift+Enter 换行（工作台普通输入框没有这条）：

- **第一行**：待办标题。
- **第二行及之后**：写入 `notes`，列表行显示首行摘要。

## 3. 清单键盘操作

焦点在今日清单时（浮层待办页或工作台今日页）：

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在未完成待办 → 习惯 →（已展开时）已完成之间移动（不打开检查器） |
| 捕获框为空再 `↓` | 退出输入，选中第一项（不打开检查器） |
| `Space` | 勾选或取消当前项，并尽量移到下一项 |
| `Return` | 打开工作台今日页并展开检查器 |
| `Delete` | 待办或习惯弹出移入回收站确认 |
| `E` | 进入标题就地编辑 |
| `Esc` | 备注或标题正在编辑时先退出输入；否则先关闭检查器；再按则取消列表焦点，回到输入框 |

也可 **双击标题** 就地改名，**单击时间胶囊** 改提醒。悬停才显示改 / 删 / ⋯。

## 4. 三栏大屏工作台

### 左侧：导航

- **聚焦**：今日待办、全局搜索。
- **看板**：四象限、安排甘特、日历。
- **记录**：灵感手记、附件中心。
- **项目 / 标签**：扁平列表，显示未完成待办数（项目角标含子树）；点 `+` 新建。右键「移入废纸篓」会确认。点某一项进入**专属清单**。
- **系统**：回收站、设置。

项目树层级与重命名在「设置 → 项目与标签」。

### 中间：今日清单

- 混排今日临时待办与常驻习惯。
- 顶部进度环只统计**临时待办**完成比例，不含习惯。
- 「昨天 N / 即将 N」是芯片，默认折叠，点开才展开。昨天区含未打卡习惯，可补勾；待办可改期到今天。点这些行会打开检查器。
- 顶部过滤条：项目（含子树）、标签、捕获来源 App。
- 未完成按四象限 → 提醒时刻 → 创建时间排序。已完成默认折叠。
- 今日页是单选焦点，**没有多选批量**。

### 项目 / 标签专属清单与批量

进入侧栏某个项目或标签后：

- **⌘ 点击** 进入多选；已在多选时单击切换选中。工具栏可全选未完成项 / 退出批量（不含已完成）。
- 底部浮现批量栏：移到今天或明天、批量完成 / 未完成、改项目、加减标签、移入回收站（有确认）。专属清单只列出待办，习惯即使挂了该项目也不出现。

### 右侧：任务检查器

点列表项或按 Return 展开；工具栏可显隐；备注正在编辑时 `Esc` 先退出输入。否则 `Esc` 先关检查器（保留选中，再点同一条会打开），再清列表焦点。方向键只换焦点，不打开检查器。若当前停在项目/标签专属清单，浮层 Return 会先回到今日清单再开检查器。日历页点选也会打开检查器（不抢月网格的方向键）。四象限卡片与甘特行名也可点开。

- 改标题、纯文本备注（自动识别 URL，可点开浏览器）、一层子任务。
- 2×2 四象限，不是九宫格。
- 排期：今天 / 明天 / **后天** / 日历任选。
- 提醒快捷点：09:00、12:00、15:00、18:00、20:00，再点或点叉取消。
- 项目与标签；抽屉里新建标签会立刻勾到当前待办或习惯。
- 待办与习惯附件：选图、粘贴；行菜单还可截当前屏。
- 习惯额外：当前连击、历史最高、今日状态；可改星期掩码（不允许一天都不选）。

## 5. 子任务与长备注

- 行内 `2/3` 胶囊，点击展开勾选。
- **只有一层**，不能再套子任务。
- 勾完父任务（含昨天芯片补勾）会级联完成未完成子任务。
- 父任务进回收站时，当时还在的子任务和附件一起进去；恢复时只还原这批，先前单独删掉的不会被救回。

## 6. 常驻习惯打卡

- 今日列表带重复图标，与待办混排。
- 打卡后行上与抽屉显示 `🔥 N`；抽屉还有历史最高。
- **⋯ → 今天跳过**：当天闭合，已完成里显示「已跳过」，连击不断。再点勾选会取消完成并清掉跳过。
- 停用：今天先不出现，连击保留；再打开时暂停那几天记为跳过。
- 仅工作日的习惯，周末不出现、不催促；周一连击仍连续。若在非排定日仍打卡，连击会 +1。
- 星期也可在习惯抽屉里改，不必只去设置。

## 7. 工作台内的其它视图

侧栏切换即可，没有「日历窗 / 更多」独立窗口菜单。

- **日历**：月网格看每日未完成数；点日期看该日清单。把**临时待办**拖到另一天格子改期（习惯不能拖）。
- **四象限**：四宫格；把卡片拖进另一象限改重要/紧急。点卡片打开检查器。可按日前后翻。
- **安排甘特**：当月横轴。临时任务是单日色块，拖到另一天改期，不能拉伸成多日工期。点行名打开检查器。习惯在适用日打点。
- **灵感手记**（长期记录本，不是一天一张日记）：
  - 打开后始终有三个分类：**密码、小巧思、日记**。写下内容，点选分类或写 `#密码`，`⌘Return` 保存。
  - 正文含「密码 / password / pwd」「巧思 / 灵感 / idea」「日记 / diary / journal」会自动打上对应分类。
  - 顶部按分类筛选（再点取消）；搜索匹配正文和标签名；置顶的排在最前。
  - **每张卡片底部都能改标签**：点 `#密码` / `#小巧思` / `#日记` 开关，漏打了保存后再补即可。
  - 密码类默认模糊，点眼睛看明文，或「复制密码」免明文拷贝。
  - 图钉置顶、双击改正文、选图、软删。浮层 ⌘Return 同样会解析标签并跳到手记页。
- **附件中心**：按待办 / 手记 / 习惯看缩略图，右键软删。
- **全局搜索**：搜待办标题、习惯名、手记正文（不搜备注、子任务、标签；不含已停用习惯）。点待办跳到日历该日并打开检查器；点习惯跳到下一个排定日；点日记进手记并滚到那一条（会清掉页内过滤）。
- **回收站**：任务、习惯、手记、附件、项目与标签都可恢复或彻底删除。

## 8. 偏好与系统设置

侧栏 **系统 → 设置**（或浮层进工作台后再打开设置）。macOS **⌘,** 仍打开系统 Settings 场景，里面是同一套设置页。

- **常驻管理**：增改习惯、提醒时刻、生效星期、项目/标签/四象限、停用。
- **项目与标签**：项目树（含子项目）与全局标签的重命名、层级；侧栏右键删除的项目/标签也在这里维护。
- **语言与外观**：跟随系统，或锁定简体中文 / English、浅色 / 深色。
- **登录自启**：开机随系统启动。
- **快捷键**：重录唤起热键与剪贴板热键（须含 ⌘ / ⌥ / ⌃）。
- **前台 App 戳记**：回车添加时附带当时前台应用。
- **截屏**：行菜单「截当前屏」需系统屏幕录制权限，只抓一张静图。
- **系统日历同步**：生成「AreaChain」专属日历。不导入其它日历的会议。专属日历上是推送并回拉：在系统日历里改标题/时间会写回待办；改成全天会清掉本机提醒时刻（全天按 GMT 民事日期写入/回拉，结束日多一天）。专属日历里事件没了，只解开绑定，不会删掉待办；无绑定的残留事件下次同步会清掉。
- **iCloud**：开关是占位。当前临时签名打开也不会改本地库。
- **数据备份**：导出 JSON（含待办子任务、备注、项目树、标签、手记分类与置顶）。图片只有元数据、没有二进制。导入前会预览新增与覆盖数量。
- **坏库**：打不开时用内存库并提示；设置里可「重置并退出」。
