# 使用说明

AreaChain 既是菜单栏上的轻量随手待办本，也是支持沉浸规划的三栏大屏工作台。

## 1. 启动与呼出

1. **菜单栏图标**：点屏幕顶端菜单栏的 **书本印章图标 +「今」** 打开主浮层；有未完成任务时旁边会显示数字。若图标被系统挤出，可点菜单栏最左侧的 `«` 展开。
2. **全局热键（浮层）**：随时按下全局热键（默认 **⌘⇧A**）快速呼出或收起菜单栏浮层。在「设置 → 偏好」中可自由修改。
3. **剪贴板极速捕获**：按下全局热键（默认 **⌘⇧V**），系统会快速读取一次当前剪贴板内容：若为文字则直接转为今天的一条待办；若为图片则作为图片附件加入；剪贴板为空时不触发。
4. **三栏大屏工作台**：在菜单栏浮层底栏点击 **工作台** 按钮（或直接通过热键与各独立窗口入口），即可唤出三栏大屏工作台窗口（`MainSplitWorkspaceView`），展开更宽阔的多维规划视野。

> **提示**：应用无 Dock 图标。关闭浮层或窗口时，输入框中尚未提交的草稿文本会自动保留，下次打开即可继续编辑。

## 2. 极速输入与智能解析技巧

在浮层或工作台顶部的输入框中：
- **回车** 或点 **添加**：保存为今天的临时待办任务。
- **⌘回车** 或点 **日记**：保存为一句今日日记，录入后依然停留在任务页，不打断思路。

### 自然语言智能解析示例

AreaChain 内置智能解析引擎，输入时可直接附带时间、标签与优先级指令，系统将自动识别并清洗标题：

| 输入格式示例 | 自动解析结果 |
|---|---|
| `下午3点半 团队周会` | 标题为「团队周会」，提醒时刻自动设为 **15:30**。 |
| `18:00 去健身房跑步 #运动` | 标题为「去健身房跑步」，时刻设为 **18:00**，自动归入标签「运动」。 |
| `!p1 提交核心技术方案` | 标题为「提交核心技术方案」，优先级自动设为 **重要且紧急**。 |
| `!重要 整理下季度规划` | 标题为「整理下季度规划」，自动标为 **重要**（象限二）。 |
| `明天中午12点 和产品经理吃午饭 !p2 #工作` | 提取时刻 **12:00**，优先级 **重要**，打上标签「工作」，标题净化为「和产品经理吃午饭」。 |

### 多行长备注极速录入

如果在输入框中粘贴或输入多行内容（Shift+Enter 换行）：
- **第一行**：自动作为待办任务的主标题。
- **第二行及后续行**：自动存入该待办的长文本备注（`notes`），列表行会自动展现首行摘要预览。

## 3. 三栏大屏工作台

三栏工作台（`MainSplitWorkspaceView`）专为大屏与重度规划设计：

### 左侧：导航与目录栏
- **视图专区**：一键切换「今日待办」、「日历视图」、「四象限矩阵」、「安排甘特」、「随手日记」、「附件中心」、「回收站」与「偏好设置」。
- **项目树列表**：展示所有项目及其当前未完成任务数，支持点击新建项目、右键重命名或删除。
- **标签列表**：展示所有标签及关联未完成任务数，支持新建与管理。

### 中间：核心清单区
- 集中呈现今日待办与常驻习惯。
- 顶部展示今日进度环（`TodayProgressCard`）与连续打卡天数。
- 支持单项选择或多选。

### 底部：浮动批量操作栏 (`BatchActionBar`)
当选中一项或多项待办时，底部自动浮现悬浮动作栏：
- **移动日期**：一键将所选项统一移到「今天」或「明天」。
- **状态切换**：批量标记为已完成或重新标为未完成。
- **设置项目**：批量指定或清除所属项目。
- **设置标签**：批量追加或移除特定标签。
- **移入回收站**：批量将所选项移入回收站。
- **关闭选择**：点击右侧 ✖️ 退出多选模式。

### 右侧：任务检查器抽屉 (`TaskDetailDrawer`)
在列表中点击任何待办或习惯，右侧即展开全功能检查器抽屉：
- **标题就地修改**：直接在抽屉顶部修改任务名称。
- **长文本备注编辑**：内嵌多行文本编辑器，随意输入详细笔记与背景材料。
- **子任务拆解面板**：随时添加子任务、回车连续输入、勾选完成或删除。
- **四象限九宫格选择器**：直观点击设定「重要/紧急」属性。
- **提醒时间与排定日期**：可视化选择提醒时分与调整目标日期。
- **项目与标签归属**：轻点关联或新建标签。
- **图文附件管理**：直接查看缩略图、添加新图片或截屏。
- **创建与来源元数据**：查看创建时间与来源 App 戳记。

## 4. 子任务与长备注日常操作

### 子任务管理
- **列表行胶囊进度**：若任务含有子任务，行内会显示如 `2/3` 的微型状态胶囊；点击胶囊可直接展开内联子任务列表，无需打开抽屉即可快速勾选。
- **级联完成**：勾选父任务完成时，其下所有子任务自动同步标记完成；在抽屉中取消完成亦可独立操作。
- **级联删除**：父任务删除进回收站时，其子任务全部安全随同保留并进站。

### 长文本备注
- 单行标题适合扫视，复杂背景放在长备注中。
- 任务行上若有备注，会自动用浅色字体提取备注第一行作为预览摘要。
- 完整内容在右侧检查器抽屉中随时查阅与编辑。

## 5. 常驻习惯打卡与连续天数

- **习惯展示**：常驻习惯在今日列表中带有专用「重复」图标，与临时待办统一混排。
- **打卡与连胜**：打卡勾选后，行上与抽屉会点亮火焰徽章 `🔥 N`，显示当前已连续打卡天数。
- **跳过与合理休假**：若当天遇到特殊情况不便执行，可在行上点击 **⋯ → 今天跳过**。当天算作正常闭合，明日继续出现，**连续打卡天数不会被打破**。
- **非排定日自动桥接**：如果在设置中将某个习惯配置为「仅周一至周五」，周六与周日无需打卡，周一打开时连击记录依然连续有效。

## 6. 多维独立视图

除了三栏工作台，所有视图均可通过浮层底栏的「日历窗」或「更多」菜单唤起独立窗口：

- **日历窗**：月历网格查看每日未完成数量；点击具体日期查看该日清单；可将**临时待办**直接拖拽到另一天的格子里实现改期（常驻习惯不可拖拽）。
- **四象限窗**：以经典四宫格展现当前日期的所有任务；将任务卡片拖入对应象限即可自动更新重要与紧急标记。
- **安排甘特窗**：以月度横轴展示排期进度；临时任务显示为条状横块，可左右拖拉改变时间；常驻习惯显示为对应日期的打点标记。
- **随手日记窗**：以更舒适的版面阅读和撰写每日一句碎碎念，支持左右键翻阅历史。
- **附件中心**：全屏统一查看所有任务与日记关联的高清图片与截屏。
- **全局搜索**：实时关键字过滤所有历史、今天与未来的待办、常驻与日记，点选结果直接联动对应日历日。
- **回收站**：误删的条目都在这里；点击「恢复」重回原清单，点击「彻底删除」或「清空」二次确认后彻底抹除。

## 7. 偏好与系统设置

点击底栏 **设置** 打开独立设置面板：
- **常驻管理**：添加新习惯、修改名称、设定提醒时刻、勾选生效星期、配置项目/标签/四象限，或停用习惯。
- **项目与标签**：维护项目树层次结构（支持子项目挂载）与全局标签。
- **语言与外观**：支持跟随系统，或强制锁定简体中文 / English，以及深色 / 浅色外观。
- **快捷键定制**：可自由重录全局唤醒热键与剪贴板捕获热键。
- **前台 App 戳记**：开启后，回车添加任务时会自动附带当前正在使用的应用程序信息。
- **截屏授权**：初次使用「截当前屏」时需在系统隐私中授权屏幕录制权限，仅用于单次静态截图，绝不后台录制。
- **系统日历同步**：开启后可在 macOS 系统日历中自动生成「AreaChain」专属日历，同步未完成临时任务。
- **数据备份与还原**：一键导出包含子任务、备注与全部元数据的完整 JSON 备份；导入时自动显示新增与覆盖预估，安全可靠。
