# 使用说明

## 打开

1. 点屏幕最顶一排的 **书本图标** 和「今」。有未完成时旁边有数字。
2. 图标被挤没时，点菜单栏左边的 `«`。
3. 或按 **⌘⇧A** 打开 / 收起同一块浮层。

没有 Dock 图标。

## 今天的任务

- 输入框打字，**回车**：加一条今天的待办。
- 点方框：勾完。勾完的进底部「已完成 N」，点那一行可展开。
- 点标题：改字，回车保存。
- 右键：删除。

## 例行项

- 上段是每天会再出现的事。
- 右键「今天跳过」：今天不再催，明天照常出现。
- 还没有例行时，浮层里点「加上一条例行」。
- 要改顺序或关掉某一条：底栏「设置」。

## 昨天

- 「昨天 N」只显示昨天没勾完的。
- 点开后今天的清单仍在上面。
- 临时待办可右键「放到今天」；例行昨天只能补勾，不会变成今天的例行欠债。

## 日记

- **⌘回车**：记一句到今天，并跳到日记页。
- 点句子可改；右键可删。
- 「看昨天」只是回顾。这时再写，仍记到今天。
- 底栏「日记窗」用更大的窗口翻今天的句子。

## 设置

- 例行项：改名、启用、上/下、右键删除。
- 登录时打开。
- 导出 / 导入 JSON。导入会先告诉你新增几条、覆盖几条，确认后才写。
- 若提示本机库打不开：当前只在内存里，关掉就没了；原文件还在。只有你点「清空本机库并退出」才会删文件。
