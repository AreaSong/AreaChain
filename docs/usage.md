# 使用说明

AreaChain 既是菜单栏上的轻量随手待办本，也是支持沉浸规划的三栏大屏工作台。

## 1. 启动与呼出

1. **菜单栏图标**：点屏幕顶端的书本图标打开主浮层。有未完成待办或未打卡习惯时，书本内显示小点；今日事项全部处理完时显示内嵌勾号；今天暂无安排时显示普通书本。准确数量在悬停提示和浮层里查看。入口固定为 24pt 宽，不常驻「今/T」、数字或 `99+`；所有标记都在图标内部，数量变化不会改变占位。
2. **全局热键（浮层）**：默认 **⌘⇧A** 呼出或收起浮层，在「设置 → 启动」中可重录。热键必须包含 ⌘ / ⌥ / ⌃ 之一，纯 Shift 无效。
3. **剪贴板捕获**：默认 **⌘⇧V** 单次读取剪贴板。有文字则**整段当作今天一条待办的标题**（保留原文并识别标签，不解析时间/优先级），同时有图也不挂图；仅图片则建待办并挂附件；为空不触发。粘贴热键不能与唤起热键相同；若改成相同，粘贴热键会停用，设置里会标明。
4. **三栏工作台**：浮层底栏的「工作台」按钮直接打开工作台并切到当前浮层对应 tab（任务→「任务」，手记→「灵感手记」）。日历、灵感手记、四象限、安排、附件、搜索、回收站都在工作台左侧切换。侧栏 **系统 → 设置** 也是同一窗口；macOS **⌘,** 仍会打开系统 Settings 场景（同一套设置页）。
5. **浮层顶部与底栏**：顶部标题与副标题解耦各模块状态（任务 Tab：未完成待办 🟠「今天还剩 N 项」、全部完成 🟢「今日待办已完成」、无待办 ⚪️「今日无待办」；手记 Tab：印章圆点「今日手记 N 篇」、无手记时羽毛笔图标「记录即刻灵感与生活」）。底栏左侧筛选、中间语法搜索、右侧工作台与「⋯」；更多菜单提供快捷键与语法帮助、设置、退出应用。底栏不再重复显示完成百分比。
6. **退出确认**：按 **⌘Q** 或选择菜单中的「退出」，都会先询问是否退出 AreaChain；点「取消」或按 **Esc** 留在应用。确认退出后，未保存的手记仍会继续询问保存、不保存或取消。关闭最后一扇窗口不会退出菜单栏应用。

浮层分「任务 / 手记」两个页签，共用底部搜索与筛选入口；「日记」仍保留为手记的一种分类。平时无 Dock 图标；打开工作台或独立手记小窗后 Dock 会出现，关闭最后一扇后再消失。

> **提示**：任务捕获草稿与浮层手记草稿都在本次运行保留，收起浮层、切换页签或搜索后再回来仍在，但不写入偏好文件。工作台窗口关掉再开会保留当前页输入状态；切离侧栏「任务」或「灵感手记」页后，原有工作台新增草稿仍不保留。手记小窗独立持有草稿，关闭及退出应用前会确认尚未保存的内容。

## 2. 极速输入与智能解析

### 浮层

- **回车**：保存为今天的临时待办（走 NLP），无需点击按钮。写出时刻时会申请通知权限。
- **⌘回车** 或点 **手记**：记入灵感手记（解析 `#标签` 并按关键字自动打上密码/小巧思/日记），然后跳到浮层手记页。
- **Shift+Enter**：插入换行，便于多行备注。捕获框为空时再按 **↓**，焦点进入清单第一项。
- **Esc**：捕获框失焦；清单有焦点时取消列表焦点，回到捕获框。浮层没有检查器。
- 浮层 **手记** 输入框采用**严格单行 34pt**（外框高度、圆角与边距与任务输入框像素级对齐，消除 Tab 切换跳动与打字时长文拉伸抖动）：回车或 ⌘Return 提交保存；也可点击输入框右侧的「⌘↩」按钮。长文本支持单行横向平滑滚动，多行文本粘贴自动保持单行模式；输入中若包含私密标签（如 `#密码`），左侧状态图标平滑切换为盾牌 `lock.shield` 🛡；保存状态以内嵌图标反馈。右侧「在小窗打开（↗）」按钮全时段可用，有草稿时转入小窗继续写，无草稿时点击直接打开空白新手记窗口；按钮在草稿为空时保持可用。下方是两行摘要列表，不在列表里展开长文。搜索与标签筛选统一使用底栏，不额外增加标签控件。
- 浮层「任务」页与工作台同一套「昨天 / 即将」芯片，以及项目 / 标签 / App 过滤条。

### 底部搜索与筛选

- 点中间搜索框或按 **⌘F**：跨所有日期搜索待办标题/备注、启用习惯的标题/备注、子任务标题与手记正文，包括已完成待办，不含软删项。结果直接显示在浮层；任务进入工作台详情，手记打开独立小窗，私密结果仍只显示隐藏标题。
- 支持普通词、多个 `#标签`、`!p1`～`!p4`、`@15:30` 及组合，例如 `会议 #工作 !p1`。输入 `#`、`!` 或 `@` 时向上展开候选；↑↓ 选择，Tab/Return 补全。搜索只查找、不创建标签；时间和优先级条件适用于待办与习惯。
- 搜索框中 **Esc** 先关闭候选，再清空搜索，再退出输入；Return/⌘Return 不创建任务或手记。清空关键词后返回当前页，保留独立的筛选条件。
- 点击/悬停筛选入口或按 **⌘⇧F**：底栏原内容退出，任务页原位换成「全部 / 高优 / 标签 / 收起」，手记页为「全部 / 标签 / 收起」，高度不变。搜索正在输入时，悬停不会抢走焦点，仍可点击或用快捷键打开筛选。
- 选项即时生效并收起；鼠标离开或按 Esc 也可收起。标签多时横向滚动，收起按钮始终可见；关键词不会因切换底栏而丢失。
- 任务与手记分别保留自己的筛选条件，切换页签互不覆盖。筛选与搜索条件取交集，不自动改写输入语法。「全部」或清除按钮只清掉筛选条件；搜索框里的 `#标签`、`!优先级` 仍然生效。没有匹配项时可以分别清空搜索或清除筛选。

### 手记条目交互与独立小窗

- **单击整行**：仅选中高亮该手记条目（不弹窗、不打断当前心智）。
- **双击整行**：呼出当前手记的独立大窗口；短记录也可打开。
- **操作按钮呼吸感**：行尾的「在小窗打开（↗）」与「⋯」操作按钮**默认隐去**，仅在鼠标悬停（Hover）或条目被选中（Selected）时优雅淡入。同一条手记只开一扇小窗，再次打开只前置已有窗口。行尾「⋯」保留复制、列表置顶、附件、删除及「在工作台打开」；修改已有分类仍可在工作台完成。
- 输入区的「在小窗打开（↗）」会把当前草稿交给小窗（空草稿直接新建），再清空来源输入，不要求先保存，不生成副本；不会因字数变多自动弹窗。
- 小窗可拖动和调整大小。默认普通窗口，点「窗口置顶」后保持在其他普通窗口上方，不反复抢焦点；它与记录的「列表置顶」相互独立。收起菜单栏不会关闭小窗。
- 小窗采用显式保存：点「保存」、⌘S 或 ⌘Return。显示已保存、未保存或失败状态；失败保留草稿。关闭或退出应用前，可保存、不保存或取消；保存失败不会关闭窗口。
- 面板、小窗和工作台引用同一条记录。外部修改会刷新未编辑的小窗；若已有草稿，则阻止覆盖并保留草稿，只有明确确认后才重新载入。原记录已删除时不自动恢复或重建。
- 私密手记的小窗默认遮罩；显式显示后才挂载正文编辑器和附件。离开窗口、切换应用、保存或外部内容/分类变化后重新遮罩。窗口标题和关闭确认不包含私密正文。窗口和草稿不自动恢复到下一次运行。

### 工作台「任务」页

- 页内标题是「今日待办」。顶部 composer **回车** 添加今天的临时待办（走 NLP）。带时刻时会申请通知权限。
- 没有「手记」按钮，也没有 ⌘Return 记手记；⌘Return 也不会当成回车新建待办。手记请到侧栏「灵感手记」，或用浮层 ⌘Return / 「⌘↩」按钮。
- 日历页、项目/标签专属清单及常驻习惯的新增使用同一套语法解析。日历新增保留选中日期。专属清单新待办记到**今天**，并带上当前项目或标签。

### 自然语言解析示例

待办与习惯的所有新增、清单行内改名及抽屉标题编辑均生效。菜单栏与工作台新增输入栏在同一行显示固定宽度的「属性 N」，点击可预览标签、提醒与优先级；不再在输入框下方新增一行。

| 输入格式示例 | 自动解析结果 |
|---|---|
| `下午3点半 团队周会` | 标题「团队周会」，提醒 **15:30**。 |
| `下午3点开会` | 标题「开会」，提醒 **15:00**。 |
| `@18:00 去健身房跑步 #运动` | 标题「去健身房跑步」，时刻 **18:00**，标签「运动」。 |
| `!p1 提交核心技术方案` | 标题「提交核心技术方案」，**重要且紧急**。 |
| `!重要 整理下季度规划` | 标题「整理下季度规划」，标为 **重要**。 |
| `中午12点和产品经理吃午饭 !p2 #工作` | 时刻 **12:00**，优先级 **重要**，标签「工作」，标题「和产品经理吃午饭」。 |

**不会发生的事**：写「明天」不会改到明天，`dayKey` 仍是今天，「明天」留在标题里。识别各行全部可挂到待办的 `#标签`，保存时统一创建或复用；`#密码` / `#小巧思` / `#日记` 留在标题里，不会变成待办标签。不解析项目名。`!p4` 会预览为「其余」（与四象限宫格同一套文案）。「修复3点问题」「下午3点问题」不当时刻。无时段的「3点去开会」会抽出 **03:00**。

### 通用标签输入

`#今日 今天很开心` 会在保存时创建或复用「今日」标签，并关联当前内容。支持多个标签、跨行标签；带空格的名称可写成 `#"项目 A"`，名称首尾空白会忽略。同名标签按大小写和全半角归一复用。选择补全仅修改草稿，保存失败会连同新建/恢复标签一起回滚。鼠标与键盘补全都保留原生撤销/重做，补全后可直接在光标处继续输入。

待办、习惯、子任务的标题会提取有效标签；备注、手记及剪贴板捕获保留原文。行内代码、代码块、Markdown 锚点链接中的符号与转义的 `\#` 不作为标签；搜索也不会把代码中的优先级或时间当筛选条件。删除文本里的标签不自动解绑，可用标签控件移除关联。项目名、标签名仍是纯文本字段。

子任务标签独立于父任务，在搜索和标签页中可单独找到，不继承父任务标签。手记与子任务只提供标签语法；它们没有独立优先级或提醒。备注的显式 `!p1`、`@18:00` 作用于所属待办/习惯，但不会把普通句子中的自然时间当成修改指令。备注在保存/⌘Return/结束编辑时提交，输入中保留草稿。

候选展开时，第一次 Esc 只关闭候选、不保存；备注再次 Esc 才结束编辑并保存。常驻标题取消或未修改就失焦，不会重新解析旧标题中的语法。

候选和属性详情都是覆盖式浮层，不挤压任务列表。同一时间只显示一个，空间不足时自动向上避让，过长内容在浮层内滚动。属性详情仅预览，修改仍通过输入原文完成；查看或收起属性详情本身不会保存。Esc 先收起浮层并保留草稿和光标；点击外部也会收起浮层，结束编辑时仍遵循对应输入框原有的保存规则。

旧库的子任务标签默认为空，旧 JSON 可继续导入；升级不批量改写旧正文。实际升级前应保留并验证完整本地数据备份。回退前先核对旧程序是否兼容当前数据；不兼容时不要直接降级启动，应先确认恢复点及可能丢失的新增数据，再按已验证的恢复方案处理。保留旧应用不等于数据备份，详见 [恢复与回退门禁](engineering.md#发行准备与回退)。

### 多行长备注

浮层和工作台新增输入均可用 Shift+Enter 换行：

- **第一行**：待办标题。
- **第二行及之后**：写入 `notes`，列表行显示首行摘要。

## 3. 清单键盘操作

### 焦点在今日清单时（浮层「任务」页或工作台「任务」页）

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在未完成待办 → 习惯 →（已展开时）已完成之间移动。不打开检查器；若检查器已打开，抽屉会跟到当前行。 |
| 捕获框为空再 `↓` | 退出输入，选中第一项（不打开检查器） |
| `Space` | 勾选或取消当前项，并尽量移到下一项。检查日跟点选走：昨天芯片上的习惯勾昨天；点回今日行再空格则勾今天。 |
| `Return` | 打开检查器。在浮层里会打开工作台「任务」页；工作台里已打开时不再重挂窗口。 |
| `Delete` | 待办或习惯弹出「移到回收站？」确认 |
| `E` | 进入清单行内标题编辑（回车或勾保存，Esc 或叉取消；点别处不保存） |
| `Esc` | 备注或**抽屉**标题正在编辑时先退出输入（抽屉标题 Esc 回滚草稿，点别处会保存）；工作台否则先关闭检查器；再按则取消列表焦点，回到输入框。浮层没有检查器。 |

### 焦点在手记列表时（浮层「手记」页）

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在手记条目之间平滑上下移动选中项。 |
| `Return` 或 `⌘O` | 打开当前选中手记的独立大窗口。 |
| `⌘C` | 复制当前选中手记的正文（自动维护私密剪贴板敏感标记）。 |
| `Delete` 或 `⌘⌫` | 弹出当前手记「移到回收站？」确认弹窗。 |
| `Esc` | 清除当前手记行的选中高亮状态。 |

任务行分成三个独立区域：左侧圆圈只完成/取消当前任务，中间标题与空白区域单击立即选中、双击就地改名，右侧 **⋯** 只打开操作菜单。改名仍是回车保存、Esc 取消；单击时间胶囊仍可改提醒。

### 任务打卡动效与防反悔机制

- **微动效与触感**：点击左侧复选框或按 `Space` 时，圆圈产生微缩放弹回，内圈对勾由贝塞尔路径实时生长描边，Mac 触控板伴随清脆微触感（Haptic）；任务标题自左向右平滑划出删除线并柔和变淡。
- **0.4 秒防反悔驻留**：打勾后任务会在原位置停留约 0.4 秒，提供明确的完成确认感；在此期间若再次点击复选框，可**原地秒级撤回**，避免误操作造成任务丢失或打乱节奏。
- **平滑折叠沉底**：驻留 0.4 秒后，任务以弹簧曲线柔和折叠下沉，收纳进底部的「已完成」折叠区域中。
- **全局数字滚轮与指示器**：顶部 Header「今天还剩 N 项」与习惯连击徽章「🔥 N」在数值变化时如滚轮般平滑垂直滚动（`.numericText`）；今日事项全清时，状态指示小圆点平滑变形为勾号。
- **无障碍降级**：系统开启「减弱动态效果」（Reduce Motion）时，自动跳过 0.4s 驻留并降级为即时无延迟响应。

日清单支持 **Shift 点击**：从上次普通点击的任务到当前任务，按可见顺序连续选择；重复 Shift 点击可以扩大或缩小范围。**⌘ 点击**增减单项，普通点击恢复单选。范围不包含折叠或筛选隐藏的任务，也不跨「昨天 / 即将」预览分区。多选后点圆圈仍只操作这一条；方向键和 Space 保持焦点行操作。

## 4. 三栏大屏工作台

### 左侧：导航

- **聚焦**：任务、常驻、搜索。
- **看板**：四象限、安排、日历。
- **记录**：灵感手记、附件。
- **项目 / 标签**：项目按树缩进，显示未完成待办数 + 今日未打卡习惯数（项目角标含子树）；点 `+` 新建。右键可「重命名」、「新建子项目」、项目可改「上级」、「移到回收站」（会确认）。点某一项进入**专属清单**。手记三个分类（密码 / 小巧思 / 日记）不出现在待办标签列表；用这三个名字新建或重命名待办标签会提示，不会静默关掉。
- **系统**：回收站、设置（只含偏好，不含习惯或目录管理）。

聚焦「常驻」页管理全部习惯（含停用项），可拖排序、打开检查器（检查日为今天）。项目树层级、重命名与新建子项目在侧栏右键，不在设置里。

### 中间：「任务」页

页内标题「今日待办」。

- 混排今日临时待办与常驻习惯。标题栏「常驻」跳到聚焦常驻页。
- 顶部进度环只统计**临时待办**完成比例，不含习惯。
- 芯片文案是「昨天 / 即将」加数字，默认折叠，点开后区块标题是「昨天未完成 / 即将」。昨天区含未打卡习惯，可补勾；待办可改期到今天。点这些行会打开检查器并记下检查日；同一习惯若也出现在今日清单，点哪边、空格就勾哪一天。
- 顶部过滤条：项目（含子树）、标签、捕获来源 App（有数据时才出现；菜单里可点「全部」清空该项）。
- 未完成按四象限 → 提醒时刻 → 创建时间排序。已完成默认折叠。
- 「任务」页支持 Shift / ⌘ 选择，但**不提供批量操作栏**；批量操作仍在项目/标签专属清单。

### 项目 / 标签专属清单与批量

进入侧栏某个项目或标签后：

- **Shift 点击**连续选择，**⌘ 点击**增减单项；普通点击恢复单选。工具栏可全选当前可见任务或退出批量操作；已完成区域展开时也包含其中的任务，折叠时不包含。
- 底部浮现批量栏：菜单「移动日期」（今天 / 明天，仅待办）、「状态」（待办完成态，习惯勾今天）、「设置项目」、「打标签」、「移到回收站」（有确认），以及「取消选择」。专属清单列出待办，以及挂了该项目/标签的习惯。
- 输入框占位是「添加任务到此项目…」或「添加带此标签的任务…」，回车后记到**今天**。
- 点习惯打开检查器时，检查日接到今天（行上勾选本来就是今天），不会沿用日历里看过的那一天。

### 右侧：任务检查器

点列表项或按 Return 展开；工具栏可显隐；备注正在编辑时 `Esc` 先退出输入。**抽屉**标题 Esc 回滚、点别处保存。清单行内改名点别处不保存。否则 `Esc` 先关检查器（保留选中，再点同一条会打开），再清列表焦点。方向键在检查器关闭时只换焦点；已打开时抽屉会跟到当前行，并带上那一行的检查日。若当前停在项目/标签专属清单，浮层 Return 会先回到「任务」页再开检查器。日历页点选也会打开检查器（不抢月网格的方向键）。四象限卡片与安排页行名也可点开。

- 改标题、纯文本备注（自动识别 URL，可点开浏览器）、一层子任务。
- 2×2 四象限，宫格是「重要且紧急 / 重要 / 紧急 / 其余」，不是九宫格。
- **仅待办**有排期：今天 / 明天 / **后天** /「选一天…」。习惯没有改期芯片，改的是「重复星期」。
- 提醒快捷点：09:00、12:00、15:00、18:00、20:00，再点或点叉取消。
- 项目与标签；抽屉里新建标签会立刻勾到当前待办或习惯。手记三分类不能建成待办标签，表单会留下说明。
- 待办与习惯附件：选图、粘贴；行菜单还可「截当前屏」（指针所在显示器）。
- 习惯额外：当前连击、历史最高、**检查日**状态（已打卡 / 已跳过 / 非计划打卡日 / 习惯已暂停 / 待打卡）；标题栏可按检查日勾选；可改「重复星期」（不允许一天都不选）。

## 5. 子任务与长备注

- 行内 `2/3` 胶囊，点击展开勾选。
- **只有一层**，不能再套子任务。
- 勾完父任务（含昨天芯片补勾）会级联完成未完成子任务。
- 父任务进回收站时，当时还在的子任务和附件一起进去；恢复时只还原这批，先前单独删掉的不会被救回。

## 6. 常驻习惯打卡

- 今日列表带重复图标，与待办混排。
- 打卡后行上与抽屉显示 `🔥 N`；抽屉还有历史最高。
- **⋯ → 今天跳过**：当天闭合，已完成里显示「已跳过」，连击不断。再点勾选会取消完成并清掉跳过。
- **关掉 / 打开**：行菜单文案是「关掉」「打开」。关掉后今天先不出现，连击保留；再打开时暂停那几天记为跳过。很久以前停用、没有暂停日期的习惯，启用时从最后一次打卡补跳过。
- 仅工作日的习惯，周末不出现、不催促；周一连击仍连续。若在非排定日仍打卡，连击会 +1。
- 星期也可在聚焦「常驻」页或习惯抽屉里改。

## 7. 工作台内的其它视图

侧栏切换即可，没有「日历窗 / 更多」独立窗口菜单。

- **日历**：月网格看每日未完成数（含未打卡习惯）；点日期看该日清单。选中日可「加到这一天」（支持语法，仍记到选中日）。把**临时待办**拖到另一天格子改期（习惯不能拖）。
- **四象限**：四宫格标题是「重要且紧急 / 重要 / 紧急 / 其余」；只列出该日未完成项，把卡片拖进另一象限改重要/紧急。点卡片打开检查器。可按日前后翻。
- **安排**：当月横轴，只显示未完成临时任务的单日色块。按住 ⌘ 点任务名或色块可增减多选，Shift 点击可连续选择；拖动选中的任一色块，全部选中任务按同一天数平移、保留日期间隔，遇到月初/月末会整体停在边界。拖动时只有一份预览，松手才保存；Esc、移出时间轴或窗口失焦取消。也可用 ←/→ 整体前移/后移一天，不能拉伸成多日工期。点行名、双击色块或按 Return 打开检查器。习惯圆点只表示适用星期，不参与改期；点习惯名时，若该习惯今天也有点则检查今天，否则检查当月第一个打点日。
- **灵感手记**（长期记录本，不是一天一张日记）：
  - 打开后始终有三个分类：**密码、小巧思、日记**。写下内容，点选分类或写 `#密码`，点「存入手记」或 `⌘Return` 保存。
  - 正文含「密码 / password / pwd」「巧思 / 灵感 / idea」「日记 / diary / journal」会自动打上对应分类。
  - 顶部按分类筛选（再点取消）；搜索匹配正文和标签名；置顶的排在最前。
  - **每张卡片底部都能改标签**：点 `#密码` / `#小巧思` / `#日记` 开关，漏打了保存后再补即可。
  - 密码类默认遮罩；启用「隐私与解锁」后，命中私密标签的正文和图片会加密，查看、复制、编辑和选图需要解锁。解锁不会自动展开其他手记。窗口或应用失焦后重新遮罩，锁定时未保存的私密草稿加密暂存于内存；再次解锁、显式显示后可继续编辑。删除确认、回收站及搜索结果不展示私密正文，附件中心不展示私密手记图片。
  - 图钉置顶、双击改正文、选图、软删。浮层 ⌘Return 同样会解析标签并跳到手记页。
- **附件**：按「临时任务 / 手记 / 常驻」看缩略图，右键「进回收站」。父项已删或不在库里的图不出现。
- **搜索**：搜待办标题/备注、习惯名/备注、手记正文；支持多个 `#标签`；`!p1`～`!p4` 和 `@15:30` 筛选待办与习惯；子任务按自身标题和独立标签搜索，不含已停用习惯。密码类结果只显示隐藏标题。结果行前是「临时 / 常驻 / 子任务 / 手记」；子任务结果打开所属任务的检查器。点待办或习惯都进**日历**并打开检查器（待办打开该日，习惯打开从今天起下一个排定日，今天该打则打开今天）；点手记打开对应的独立小窗，私密内容仍保持遮罩；浮层记录菜单中的「在工作台打开」仍会定位到原记录。
- **回收站**：种类文案是「任务 / 常驻 / 手记 / 附件 / 项目 / 标签」。可「恢复」或「彻底删除」，顶栏「清空」。父项还在回收站或已经不在时不能单独恢复附件（说明「请先恢复所属待办、习惯或手记」）。

## 8. 偏好与系统设置

侧栏 **系统 → 设置**（或浮层进工作台后再打开设置）。macOS **⌘,** 仍打开系统 Settings 场景，里面是同一套设置页。习惯增改在聚焦「常驻」；项目改名与层级、标签改名在侧栏右键。

- **外观**：语言（系统 / 中文 / English）与外观（系统 / 浅色 / 深色），都在这一组。
- **启动**：「登录时打开」；热键「打开浮层」「剪贴板加今天」（须含 ⌘ / ⌥ / ⌃）。两者不能相同，相同时剪贴板热键停用，设置里会标明。
- **捕获**：「记下当时的 App」。打开后，浮层回车、工作台「任务」页输入、剪贴板热键、日历页和项目/标签清单添加待办会附带当时前台应用；前台是 AreaChain 自己则不写。同组还有「截当前屏」说明：要一次屏幕录制权限，只拍指针所在那块屏的一张静图。
- **通知**：显示当前授权状态，可点「允许通知」。
- **系统日历**：「把临时任务同步到系统日历」。使用「AreaChain」专属日历，不导入其它日历会议。单边修改才传播；两边同时修改或旧绑定无法确认时保留双方，设置会列出需核对的待办。将双方标题、日期和提醒核对一致后点「重新同步」。远端删除只解绑，普通编辑不会自动重建，完成后重新打开待办可重新发布。坏库降级/读取失败时不写日历；未知遗留事件保留，不自动清理。
- **iCloud**：开关只保存偏好，此版本尚未接入 CloudKit 同步，不会改变数据存放位置。
- **隐私与解锁**：管理私密标签、系统验证和独立主密码，设置 1／5／15 分钟闲置锁定、立即锁定，以及加密备份与恢复。默认 5 分钟；锁屏、休眠或退出时立即锁定。
- **数据**：「导出 JSON」「导入 JSON」（含普通待办、子任务及其独立标签、备注、项目树、标签、普通手记分类与置顶）。普通 JSON 排除受保护及旧密码遮罩手记和其附件，并提示排除数量；不含图片二进制。导入前预览新增与覆盖数量，不能覆盖已有私密手记、其附件或绕过私密标签规则。完整备份请使用「隐私与解锁」内的加密备份。
- **坏库**：打不开时用内存库并提示；设置里可「清空本机库并退出」。

保存失败会明确提示，新增输入不会提前清空；备注会显示「未保存」并在本次运行保留草稿，可回到原项重试。导入冲突会拒绝整个导入，不自动去重清洗。文件清理失败的附件仍留在回收站，可在修复权限后再次删除。未启用隐私保护的旧密码遮罩仍只是屏幕防窥；已有明文备份不会自动变安全。

## 9. 隐私保护、备份与恢复

### 首次启用

1. 打开「设置 → 隐私与解锁 → 设置私密保护」，选择受保护标签。命中任意一个私密标签，即保护整条手记正文和所属图片；第一版不保护待办、习惯的正文。
2. 选择系统验证、独立主密码或两者同时启用。主密码至少 12 个字符、最多 4096 个 UTF-8 字节；应用不接收 Mac 登录密码。钥匙串不可用时会说明原因，可选择主密码，不会降级为无访问控制的系统存储。
3. 核对受影响的已有手记数量；可包含旧密码遮罩内容和回收站中的记录。涉及已有数据时，先用独立备份口令保存加密备份，应用回读验证通过后才转换。
4. 转换先写新的附件密文，再提交数据库；提交失败保留原数据。若显示「存储清理尚未完成」，先重试附件清理，再退出并重新打开应用，完成数据库历史明文清理。待清理附件不会被下一轮转换覆盖追踪信息。

### 解锁与保护规则

| 配置 | 行为 |
|---|---|
| 仅系统验证 | 通过 macOS 原生界面使用 Touch ID 或 Mac 登录密码；依赖本机钥匙串及应用签名。 |
| 仅独立主密码 | 只通过 AreaChain 主密码解锁，不保留可绕过它的系统解锁入口。 |
| 两者同时启用 | 任意一种验证成功即可，不是双重验证；知道 Mac 登录密码的人仍可能通过系统方式解锁。 |

所有标签共用同一私密锁。新增、更换或关闭方式需重新验证，至少保留一种经过验证的方式。系统凭据删除失败会明确报错；若提示清理待完成，需按提示重试，不能把按钮消失视为凭据已完全撤销。

标签改名、删除、移除关联、取消私密标签规则，以及进入或恢复回收站，都不会自动解除已有记录的保护。要解除保护，先移除仍在生效的私密标签关联，再在卡片菜单选择「解除保护」，确认并重新验证。

锁定时正文不参与搜索；解锁后在内存中搜索，不建立明文持久化索引。正在编辑的卡片即使因锁定暂时消失于搜索结果，草稿也会保留。复制私密内容时附带敏感及临时标记，30 秒后仅在剪贴板仍是本次内容时清理；不会覆盖之后复制的内容，也不能撤回第三方剪贴板历史。

### 备份与恢复

「加密备份」包含普通及私密记录、标签、回收站状态和图片二进制，使用独立备份口令，不依赖原 Mac 的钥匙串。请把口令与备份分开妥善保管。

换机后先配置新的私密锁，再选择「恢复加密备份」、输入备份口令并确认预览。恢复会合并并可能覆盖同 ID 记录；已有本地标签规则不会被备份静默改写，恢复为私密的手记及其保留的本地图片均受保护。错误口令、损坏备份或提交失败不会用不完整内容替换原数据。当前单张图片上限 64 MiB、备份清单上限 16 MiB，超限会报错而非跳过文件。

所有解锁凭据与备份口令都丢失时，不能承诺找回。不要删除隐私配置或安装不支持加密格式的旧版应用作为回滚；应保留原库、附件与配置，使用兼容版本或经确认的备份恢复。标签名、日期等元数据仍可见；已有外部明文备份、原始图片、已复制内容及系统被攻陷后的截取不在完整防护范围内。

真实数据启用前还需验证本机系统认证、应用重编译／升级后的钥匙串可读性，以及备份恢复。隔离测试通过不代表真实数据已经迁移，也不代表已替换现用应用。
