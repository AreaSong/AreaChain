# 使用说明

## 打开

1. 点屏幕最顶一排的 **书本图标** 和「今」。有未完成时旁边有数字。
2. 图标被挤没时，点菜单栏左边的 `«`。
3. 或按底栏显示的全局热键（默认 **⌘⇧A**）打开 / 收起同一块浮层。设置里可改。
4. **⌘⇧V**（可改）把剪贴板变成今天一条：有字用字；只有图则标题为「图片」并挂上图；空则不加。

没有 Dock 图标。关掉浮层时，输入框里没提交的字下次打开还在。

## 今天的任务

浮层只有 **任务** 和 **日记** 两页。任务页就是今天这一张清单；常驻不另开一段，只在行上用 **重复符号** 标出来。勾完的进「已完成」。

- 顶上输入框 **回车** 或点 **添加**：今天的临时任务。
- 点 **日记** 或 **⌘回车**：记一句今天的日记，仍留在任务页。
- 点方框：勾完。勾完的留在「已完成」，默认可看见；点那一行可收起。
- 临时任务：点标题改字。鼠标移到这一行才出铅笔和垃圾桶；右边 **⋯** 可设时刻、改到某天、标项目/标签/重要紧急、附上图片或截当前屏、删除。删除会问一次，确认后进回收站。
- 常驻带重复符号：勾选，或 **⋯ → 今天跳过**。改名、时刻、哪几天出现、项目/标签/四象限、关掉、删除去底栏 **设置**。行上两个小点表示重要 / 紧急。
- 今天清单上方，有项目、标签或 App 戳时才出现过滤。日历窗没有这排过滤。
- 改字时点对勾保存，叉取消；回车一样保存。
- 设了时刻才跟在标题后面。没设时刻就不会响。

## 常驻

- 按你勾的星期出现在今天的清单里，行上有重复符号。
- 底栏 **设置 → 常驻** 里新增、改名、设时刻、勾星期几、标项目/标签/重要紧急、关掉或删掉（确认后进回收站）。不要用顶上那个框加常驻。
- 关掉的明天起不再出现，还在设置里，开关打开就回来。
- 没勾的那天不会出现，也不会在那天通知。全周都勾就是每天；只勾周一到周五就跟以前的「仅工作日」一样。
- 「今天跳过」：今天不再催，明天照常出现。

## 通知

- 第一次给某条设时刻时，系统会问能不能通知。设置里也可以再点「允许通知」。
- 到点会弹出本机横幅。常驻在你勾的那天响一次；临时只在那一天响一次。
- 勾完、跳过、关掉或清掉时刻后，这条就不会再响。

## 昨天 / 即将

- 「昨天 N」只在昨天真有没勾完时出现。
- 「即将 N」只在已经排到明天或更后时出现。
- 点开后今天的清单仍在上面。
- 临时任务可右键改到今天、明天或自选的一天；常驻昨天只能补勾，不会变成今天的欠债。

## 日记

- 切到日记页。上面可以写新句子并点「添加」。
- 每一行左边是写下的时刻。点句子可改；鼠标移上去才出铅笔、图片和垃圾桶，确认后进回收站。可附上图片、从剪贴板贴图或截当前屏，缩略图点开展示。
- 左右箭头按日往回翻。这时再写，仍记到今天；点「回今天」回到当天。
- 底栏「日记窗」用更大的窗口翻句子。

## 日历

- 底栏点「日历窗」。上面是月网格，格子里的数字是那天还没勾完的条数；今天描一圈。
- 点某一天，下面是那天的清单：常驻按你勾的星期出现，临时按排到那天的。
- 可以把**临时**任务拖到另一个日子格子，改的是排到哪一天。常驻拖不动。
- 输入框加的是 **这一天** 的临时任务，不是永远加到今天。
- 可以勾选、跳过；改常驻出现在星期几仍去设置。
- 左右翻月。不在今天时点「回今天」。
- 浮层任务页仍只显示今天，不会跟着日历翻走。

## 附件 / 四象限 / 安排

- 底栏 **更多** 里打开。浮层宽度不够，不跟设置、日记、日历、回收站挤在同一排。
- **附件**：按临时任务 / 日记分组看缩略图，点开展示。右键软删，文件还在，回收站里可恢复或彻底删。
- **四象限**：当天（可翻日）的临时和常驻分成四宫。拖进某一宫只改重要 / 紧急。浮层仍是清单加点。
- **安排**：当月横轴。临时任务当天一格，可拖到另一天；常驻只在符合星期的日子打点，不画跨周条。

## 回收站

- 底栏点「回收站」。误删的任务、常驻、日记和附件都在这里。
- **恢复** 回到原来的清单；**彻底删除** 或 **清空** 会再问一次，之后就没了。

## 设置

- 浮层底栏点「设置」。没有 Dock，窗口会自己跑到前台。左上角红点只关这个窗口，应用还在菜单栏；要退出只能点浮层底栏「退出」。设置、日记、日历、回收站、附件、四象限、安排都一样。
- 最上面是常驻：加一条、改名、开关、勾星期几、时刻、项目/标签/四象限。删除确认后进回收站。
- 下面是项目和标签。项目可以挂到另一个下面（不能成环）；过滤某个项目时带上子孙。没有成员或协作。
- 语言和外观默认跟 macOS，也可强制简体中文 / English，浅色 / 深色。你写的任务、日记名称不翻译。菜单栏「今」两语都保留。
- 登录时打开。点「打开浮层」再按下新组合，可改全局热键；Esc 取消。空按或注册失败会回到 ⌘⇧A。「剪贴板加今天」默认 ⌘⇧V，不能和打开浮层撞车。
- 「记下当时的 App」默认关。打开后，浮层回车和剪贴板热键会记下前台 App；不读窗口标题。日历窗里手打的不加戳。
- 「截当前屏」要一次屏幕录制权限，只拍静图。沙盒拦住时仍可选文件或贴图。
- 「允许通知」再向系统要一次权限。
- 「把临时任务同步到系统日历」默认关。打开后会要日历权限，只写 AreaChain 专用日历，不收别人的会议。到点仍是本机通知。
- iCloud 同步开关：当前没有开发者账号和容器时只是说明，打开也不会改本地库。
- 导出 / 导入 JSON。导入会先告诉你新增几条、覆盖几条，确认后才写。附件文件不进 JSON。
- 若提示本机库打不开：当前只在内存里，关掉就没了；原文件还在。只有你点「清空本机库并退出」才会删文件。
