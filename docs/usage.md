# 使用说明

## 打开

1. 点屏幕最顶一排的 **书本图标** 和「今」。有未完成时旁边有数字。
2. 图标被挤没时，点菜单栏左边的 `«`。
3. 或按底栏显示的全局热键（默认 **⌘⇧A**）打开 / 收起同一块浮层。设置里可改。

没有 Dock 图标。关掉浮层时，输入框里没提交的字下次打开还在。

## 今天的任务

- 输入框 **回车** 加到今天。
- **⌘回车** 记一句今天的日记，仍留在任务页。
- 点方框：勾完。勾完的留在「已完成」，默认可看见；点那一行可收起。
- 点标题：改字，回车保存。
- 右键：删除，或改到今天 / 明天 / 自选的一天。改到未来的条目进「即将 N」（有才出现），不占今天角标。

## 例行项

- 今天该出现的例行在上段。没有例行时这段不出现。
- 标了「仅工作日」的，周六日不会出现。
- 右键「今天跳过」：今天不再催，明天照常出现。
- 改模板（加、关、仅工作日、排序）：浮层切到「例行」页。右键删除。

## 昨天 / 即将

- 「昨天 N」只在昨天真有没勾完时出现。
- 「即将 N」只在已经排到明天或更后时出现。
- 点开后今天的清单仍在上面。
- 临时待办可右键改到今天、明天或自选的一天；例行昨天只能补勾，不会变成今天的例行欠债。

## 日记

- **⌘回车**：记一句到今天，不跳页。
- 要看历史：切到日记页。点句子可改；右键可删。
- 左右箭头按日往回翻。这时再写，仍记到今天；点「回今天」回到当天。
- 底栏「日记窗」用更大的窗口翻句子。

## 设置

- 浮层底栏点「设置」。没有 Dock，窗口会自己跑到前台。左上角红点只关这个窗口，应用还在菜单栏；要退出只能点浮层底栏「退出」。
- 语言和外观默认跟 macOS，也可强制简体中文 / English，浅色 / 深色。你写的待办、日记、例行名称不翻译。菜单栏「今」两语都保留。
- 登录时打开。点「打开浮层」再按下新组合，可改全局热键；Esc 取消。空按或注册失败会回到 ⌘⇧A。
- 导出 / 导入 JSON。导入会先告诉你新增几条、覆盖几条，确认后才写。
- 若提示本机库打不开：当前只在内存里，关掉就没了；原文件还在。只有你点「清空本机库并退出」才会删文件。
