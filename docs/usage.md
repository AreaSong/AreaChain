# 使用说明

AreaChain 既是菜单栏上的轻量随手待办本，也是支持沉浸规划的三栏大屏工作台。

## 1. 启动与呼出

1. **菜单栏图标**：点屏幕顶端菜单栏的 **书本印章图标 +「今」**（英文界面为 `T`）打开主浮层；有未完成时显示数字（如 `今3`），数字含未打卡习惯。若图标被系统挤出，可点菜单栏最左侧的 `«` 展开。
2. **全局热键（浮层）**：默认 **⌘⇧A** 呼出或收起浮层，在「设置 → 启动」中可重录。热键必须包含 ⌘ / ⌥ / ⌃ 之一，纯 Shift 无效。
3. **剪贴板捕获**：默认 **⌘⇧V** 单次读取剪贴板。有文字则**整段当作今天一条待办的标题**（不解析时间/标签/优先级），同时有图也不挂图；仅图片则建待办并挂附件；为空不触发。粘贴热键不能与唤起热键相同；若改成相同，粘贴热键会停用，设置里会标明。
4. **三栏工作台**：浮层标题栏的展开按钮打开工作台并切到当前浮层对应 tab（任务→「任务」，日记→「灵感手记」）。底栏 **工作台** 只前置同一扇窗，不把你从日历、灵感手记拉回「任务」页。日历、灵感手记、四象限、安排、附件、搜索、回收站都在工作台左侧切换。侧栏 **系统 → 设置** 也是同一窗口；macOS **⌘,** 仍会打开系统 Settings 场景（同一套设置页）。
5. **浮层底栏**：工作台、设置齿轮（打开工作台「设置」页，不是 ⌘,）、当前唤起热键、退出应用。

浮层分「任务 / 日记」两个页签。平时无 Dock 图标；打开工作台后 Dock 会出现，关掉工作台再消失。

> **提示**：关浮层后再开，捕获框里未提交的草稿会保留。工作台窗口关掉再开也会保留当前页的输入状态；切离侧栏「任务」页后，页内 composer 草稿会丢。浮层「日记」页 / 工作台「灵感手记」的「存入手记」草稿切走页签后也会丢。

## 2. 极速输入与智能解析

### 浮层

- **回车** 或点 **添加**：保存为今天的临时待办（走 NLP）。写出时刻时会申请通知权限。
- **⌘回车** 或点 **日记**：记入灵感手记（解析 `#标签` 并按关键字自动打上密码/小巧思/日记），然后跳到浮层日记页。
- **Shift+Enter**：插入换行，便于多行备注。捕获框为空时再按 **↓**，焦点进入清单第一项。
- **Esc**：捕获框失焦；清单有焦点时取消列表焦点，回到捕获框。浮层没有检查器。
- 浮层 **日记** 页就是灵感手记：可在页内写完后点「存入手记」或 ⌘Return，不必先走捕获框。
- 浮层「任务」页与工作台同一套「昨天 / 即将」芯片，以及项目 / 标签 / App 过滤条。

### 工作台「任务」页

- 页内标题是「今日待办」。顶部 composer **回车** 添加今天的临时待办（走 NLP）。带时刻时会申请通知权限。
- 没有「日记」按钮，也没有 ⌘Return 记手记；⌘Return 也不会当成回车新建待办。手记请到侧栏「灵感手记」，或用浮层 ⌘Return / 「存入手记」。
- 日历页、项目/标签专属清单里的添加是纯标题，不跑 NLP。专属清单新待办记到**今天**，并带上当前项目或标签。

### 自然语言解析示例

仅浮层与工作台「任务」页 composer 添加待办时生效。输入时会出现时间 / 标签 / 优先级胶囊预览。

| 输入格式示例 | 自动解析结果 |
|---|---|
| `下午3点半 团队周会` | 标题「团队周会」，提醒 **15:30**。 |
| `下午3点开会` | 标题「开会」，提醒 **15:00**。 |
| `@18:00 去健身房跑步 #运动` | 标题「去健身房跑步」，时刻 **18:00**，标签「运动」。 |
| `!p1 提交核心技术方案` | 标题「提交核心技术方案」，**重要且紧急**。 |
| `!重要 整理下季度规划` | 标题「整理下季度规划」，标为 **重要**。 |
| `中午12点和产品经理吃午饭 !p2 #工作` | 时刻 **12:00**，优先级 **重要**，标签「工作」，标题「和产品经理吃午饭」。 |

**不会发生的事**：写「明天」不会改到明天，`dayKey` 仍是今天，「明天」留在标题里。只取第一个 `#标签`。不解析项目名。`!p4` 会预览为「其余」（与四象限宫格同一套文案）。「修复3点问题」「下午3点问题」不当时刻。无时段的「3点去开会」会抽出 **03:00**。

### 多行长备注

浮层用 Shift+Enter 换行（工作台普通输入框没有这条）：

- **第一行**：待办标题。
- **第二行及之后**：写入 `notes`，列表行显示首行摘要。

## 3. 清单键盘操作

焦点在今日清单时（浮层「任务」页或工作台「任务」页）：

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在未完成待办 → 习惯 →（已展开时）已完成之间移动。不打开检查器；若检查器已打开，抽屉会跟到当前行。 |
| 捕获框为空再 `↓` | 退出输入，选中第一项（不打开检查器） |
| `Space` | 勾选或取消当前项，并尽量移到下一项。检查日跟点选走：昨天芯片上的习惯勾昨天；点回今日行再空格则勾今天。 |
| `Return` | 打开检查器。在浮层里会打开工作台「任务」页；工作台里已打开时不再重挂窗口。 |
| `Delete` | 待办或习惯弹出「移到回收站？」确认 |
| `E` | 进入清单行内标题编辑（回车或勾保存，Esc 或叉取消；点别处不保存） |
| `Esc` | 备注或**抽屉**标题正在编辑时先退出输入（抽屉标题 Esc 回滚草稿，点别处会保存）；工作台否则先关闭检查器；再按则取消列表焦点，回到输入框。浮层没有检查器。 |

也可 **双击标题** 就地改名（同上：回车保存，Esc 取消），**单击时间胶囊** 改提醒。悬停才显示改 / 删 / ⋯。

## 4. 三栏大屏工作台

### 左侧：导航

- **聚焦**：任务、常驻、搜索。
- **看板**：四象限、安排、日历。
- **记录**：灵感手记、附件。
- **项目 / 标签**：项目按树缩进，显示未完成待办数 + 今日未打卡习惯数（项目角标含子树）；点 `+` 新建。右键可「重命名」、「新建子项目」、项目可改「上级」、「移到回收站」（会确认）。点某一项进入**专属清单**。手记三个分类（密码 / 小巧思 / 日记）不出现在待办标签列表。
- **系统**：回收站、设置（只含偏好，不含习惯或目录管理）。

聚焦「常驻」页管理全部习惯（含停用项），可拖排序、打开检查器。项目树层级、重命名与新建子项目在侧栏右键，不在设置里。

### 中间：「任务」页

页内标题「今日待办」。

- 混排今日临时待办与常驻习惯。标题栏「常驻」跳到聚焦常驻页。
- 顶部进度环只统计**临时待办**完成比例，不含习惯。
- 芯片文案是「昨天 / 即将」加数字，默认折叠，点开后区块标题是「昨天未完成 / 即将」。昨天区含未打卡习惯，可补勾；待办可改期到今天。点这些行会打开检查器并记下检查日；同一习惯若也出现在今日清单，点哪边、空格就勾哪一天。
- 顶部过滤条：项目（含子树）、标签、捕获来源 App（有数据时才出现；菜单里可点「全部」清空该项）。
- 未完成按四象限 → 提醒时刻 → 创建时间排序。已完成默认折叠。
- 「任务」页是单选焦点，**没有多选批量**。

### 项目 / 标签专属清单与批量

进入侧栏某个项目或标签后：

- **⌘ 点击** 进入多选；已在多选时单击切换选中。工具栏「全选/进入批量操作」与「退出批量操作」（全选不含已完成）。
- 底部浮现批量栏：菜单「移动日期」（今天 / 明天，仅待办）、「状态」（待办完成态，习惯勾今天）、「设置项目」、「打标签」、「移到回收站」（有确认），以及「取消选择」。专属清单列出待办，以及挂了该项目/标签的习惯。
- 输入框占位是「添加任务到此项目…」或「添加带此标签的任务…」，回车后记到**今天**。

### 右侧：任务检查器

点列表项或按 Return 展开；工具栏可显隐；备注正在编辑时 `Esc` 先退出输入。**抽屉**标题 Esc 回滚、点别处保存。清单行内改名点别处不保存。否则 `Esc` 先关检查器（保留选中，再点同一条会打开），再清列表焦点。方向键在检查器关闭时只换焦点；已打开时抽屉会跟到当前行，并带上那一行的检查日。若当前停在项目/标签专属清单，浮层 Return 会先回到「任务」页再开检查器。日历页点选也会打开检查器（不抢月网格的方向键）。四象限卡片与安排页行名也可点开。

- 改标题、纯文本备注（自动识别 URL，可点开浏览器）、一层子任务。
- 2×2 四象限，宫格是「重要且紧急 / 重要 / 紧急 / 其余」，不是九宫格。
- **仅待办**有排期：今天 / 明天 / **后天** /「选一天…」。习惯没有改期芯片，改的是「重复星期」。
- 提醒快捷点：09:00、12:00、15:00、18:00、20:00，再点或点叉取消。
- 项目与标签；抽屉里新建标签会立刻勾到当前待办或习惯。
- 待办与习惯附件：选图、粘贴；行菜单还可「截当前屏」（指针所在显示器）。
- 习惯额外：当前连击、历史最高、**检查日**状态（已打卡 / 已跳过 / 非计划打卡日 / 习惯已暂停 / 待打卡）；标题栏可按检查日勾选；可改「重复星期」（不允许一天都不选）。

## 5. 子任务与长备注

- 行内 `2/3` 胶囊，点击展开勾选。
- **只有一层**，不能再套子任务。
- 勾完父任务（含昨天芯片补勾）会级联完成未完成子任务。
- 父任务进回收站时，当时还在的子任务和附件一起进去；恢复时只还原这批，先前单独删掉的不会被救回。

## 6. 常驻习惯打卡

- 今日列表带重复图标，与待办混排。
- 打卡后行上与抽屉显示 `🔥 N`；抽屉还有历史最高。
- **⋯ → 今天跳过**：当天闭合，已完成里显示「已跳过」，连击不断。再点勾选会取消完成并清掉跳过。
- **关掉 / 打开**：行菜单文案是「关掉」「打开」。关掉后今天先不出现，连击保留；再打开时暂停那几天记为跳过。很久以前停用、没有暂停日期的习惯，启用时从最后一次打卡补跳过。
- 仅工作日的习惯，周末不出现、不催促；周一连击仍连续。若在非排定日仍打卡，连击会 +1。
- 星期也可在聚焦「常驻」页或习惯抽屉里改。

## 7. 工作台内的其它视图

侧栏切换即可，没有「日历窗 / 更多」独立窗口菜单。

- **日历**：月网格看每日未完成数（含未打卡习惯）；点日期看该日清单。选中日可「加到这一天」（纯标题，记到该日）。把**临时待办**拖到另一天格子改期（习惯不能拖）。
- **四象限**：四宫格标题是「重要且紧急 / 重要 / 紧急 / 其余」；只列出该日未完成项，把卡片拖进另一象限改重要/紧急。点卡片打开检查器。可按日前后翻。
- **安排**：侧栏名「安排」。当月横轴。只显示未完成临时任务的单日色块，拖到另一天改期，不能拉伸成多日工期。点行名打开检查器。习惯在当月适用星期打点；点习惯名时，若该习惯今天也有点则检查今天，否则检查当月第一个打点日。
- **灵感手记**（长期记录本，不是一天一张日记）：
  - 打开后始终有三个分类：**密码、小巧思、日记**。写下内容，点选分类或写 `#密码`，点「存入手记」或 `⌘Return` 保存。
  - 正文含「密码 / password / pwd」「巧思 / 灵感 / idea」「日记 / diary / journal」会自动打上对应分类。
  - 顶部按分类筛选（再点取消）；搜索匹配正文和标签名；置顶的排在最前。
  - **每张卡片底部都能改标签**：点 `#密码` / `#小巧思` / `#日记` 开关，漏打了保存后再补即可。
  - 密码类默认模糊，点眼睛看明文，或「复制密码」免明文拷贝。模糊时不能编辑、不能选图、不显示附件缩略图。
  - 图钉置顶、双击改正文、选图、软删。浮层 ⌘Return 同样会解析标签并跳到日记页。
- **附件**：按「临时任务 / 日记 / 常驻」看缩略图，右键「进回收站」。父项已删或不在库里的图不出现。
- **搜索**：搜待办标题、习惯名、手记正文（不搜备注、子任务、标签；不含已停用习惯）。结果行前是「临时 / 常驻 / 日记」。点待办或习惯都进**日历**并打开检查器（待办打开该日，习惯打开从今天起下一个排定日，今天该打则打开今天）；点日记进「灵感手记」并滚到那一条（会清掉页内过滤）。切离「灵感手记」tab 后，这条高亮会清掉。
- **回收站**：种类文案是「任务 / 常驻 / 日记 / 附件 / 项目 / 标签」。可「恢复」或「彻底删除」，顶栏「清空」。父项还在回收站或已经不在时不能单独恢复附件（说明「请先恢复所属待办、习惯或手记」）。

## 8. 偏好与系统设置

侧栏 **系统 → 设置**（或浮层进工作台后再打开设置）。macOS **⌘,** 仍打开系统 Settings 场景，里面是同一套设置页。习惯增改在聚焦「常驻」；项目改名与层级、标签改名在侧栏右键。

- **外观**：语言（系统 / 中文 / English）与外观（系统 / 浅色 / 深色），都在这一组。
- **启动**：「登录时打开」；热键「打开浮层」「剪贴板加今天」（须含 ⌘ / ⌥ / ⌃）。两者不能相同，相同时剪贴板热键停用，设置里会标明。
- **捕获**：「记下当时的 App」。打开后，浮层回车、工作台「任务」页输入、剪贴板热键、日历页和项目/标签清单添加待办会附带当时前台应用；前台是 AreaChain 自己则不写。同组还有「截当前屏」说明：要一次屏幕录制权限，只拍指针所在那块屏的一张静图。
- **通知**：显示当前授权状态，可点「允许通知」。
- **系统日历**：「把临时任务同步到系统日历」。生成「AreaChain」专属日历。不导入其它日历的会议。专属日历上是推送并回拉：在系统日历里改标题/时间会写回待办；改成全天会清掉本机提醒时刻（全天按 GMT 民事日期写入/回拉，结束日多一天）。专属日历里事件没了，只解开绑定，不会删掉待办；无绑定的残留事件下次同步会清掉。
- **iCloud**：开关「iCloud 同步」会写入偏好，但本地库不会因此改成 CloudKit。当前签名打开也不会改数据存放位置。
- **数据**：「导出 JSON」「导入 JSON」（含待办子任务、备注、项目树、标签、手记分类与置顶）。图片只有元数据、没有二进制。导入前会预览：例行 / 待办 / 日记 / 勾选 / 项目 / 标签 / 附件的新增与覆盖数量。
- **坏库**：打不开时用内存库并提示；设置里可「清空本机库并退出」。
