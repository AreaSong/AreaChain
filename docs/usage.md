# 使用说明

## 打开

1. 点屏幕最顶一排的 **书本图标** 和「今」。有未完成时旁边有数字。
2. 图标被挤没时，点菜单栏左边的 `«`。
3. 或按底栏显示的全局热键（默认 **⌘⇧A**）打开 / 收起同一块浮层。设置里可改。

没有 Dock 图标。关掉浮层时，输入框里没提交的字下次打开还在。

## 今天的任务

浮层只有 **任务** 和 **日记** 两页。任务页就是今天这一张清单；常驻不另开一段，只在行上用 **重复符号** 标出来。勾完的进「已完成」。

- 顶上输入框 **回车** 或点 **添加**：今天的临时任务。
- 点 **日记** 或 **⌘回车**：记一句今天的日记，仍留在任务页。
- 点方框：勾完。勾完的留在「已完成」，默认可看见；点那一行可收起。
- 临时任务：点标题改字。鼠标移到这一行才出铅笔和垃圾桶；右边 **⋯** 可设时刻、改到某天、删除。删除会问一次，确认后进回收站。
- 常驻带重复符号：勾选，或 **⋯ → 今天跳过**。改名、时刻、仅工作日、关掉、删除去底栏 **设置**。
- 改字时点对勾保存，叉取消；回车一样保存。
- 设了时刻才跟在标题后面。没设时刻就不会响。

## 常驻

- 每天（或仅工作日）出现在今天的清单里，行上有重复符号。
- 底栏 **设置 → 常驻** 里新增、改名、设时刻、标仅工作日、关掉或删掉（确认后进回收站）。不要用顶上那个框加常驻。
- 关掉的明天起不再出现，还在设置里，开关打开就回来。
- 标了「仅工作日」的，周六日不会出现，也不会在那天通知。
- 「今天跳过」：今天不再催，明天照常出现。

## 通知

- 第一次给某条设时刻时，系统会问能不能通知。设置里也可以再点「允许通知」。
- 到点会弹出本机横幅。常驻每天（或每个工作日）响一次；临时只在那一天响一次。
- 勾完、跳过、关掉或清掉时刻后，这条就不会再响。

## 昨天 / 即将

- 「昨天 N」只在昨天真有没勾完时出现。
- 「即将 N」只在已经排到明天或更后时出现。
- 点开后今天的清单仍在上面。
- 临时任务可右键改到今天、明天或自选的一天；常驻昨天只能补勾，不会变成今天的欠债。

## 日记

- 切到日记页。上面可以写新句子并点「添加」。
- 每一行左边是写下的时刻。点句子可改；鼠标移上去才出铅笔和垃圾桶，确认后进回收站。
- 左右箭头按日往回翻。这时再写，仍记到今天；点「回今天」回到当天。
- 底栏「日记窗」用更大的窗口翻句子。

## 回收站

- 底栏点「回收站」。误删的任务、常驻、日记都在这里。
- **恢复** 回到原来的清单；**彻底删除** 或 **清空** 会再问一次，之后就没了。

## 设置

- 浮层底栏点「设置」。没有 Dock，窗口会自己跑到前台。左上角红点只关这个窗口，应用还在菜单栏；要退出只能点浮层底栏「退出」。
- 最上面是常驻：加一条、改名、开关、仅工作日、时刻。删除确认后进回收站。
- 语言和外观默认跟 macOS，也可强制简体中文 / English，浅色 / 深色。你写的任务、日记名称不翻译。菜单栏「今」两语都保留。
- 登录时打开。点「打开浮层」再按下新组合，可改全局热键；Esc 取消。空按或注册失败会回到 ⌘⇧A。
- 「允许通知」再向系统要一次权限。
- 导出 / 导入 JSON。导入会先告诉你新增几条、覆盖几条，确认后才写。
- 若提示本机库打不开：当前只在内存里，关掉就没了；原文件还在。只有你点「清空本机库并退出」才会删文件。
