# 产品定位

AreaChain 是专为 macOS 打造的个人任务看板与习惯打卡助手：菜单栏随手唤出、支持自然语言输入的轻量便签本，加上一扇三栏工作台做规划与批量管理。数据存放于本机，无广告、无账号。

## 一句话

对外以「个人任务与习惯养成」为核心。常驻习惯按周期重现并追踪连续打卡天数（Streak），临时待办支持一层子任务与长文本备注，两端均可到点通知。灵感手记是旁路，用来记小巧思、密码备忘和碎碎念。

## 双重交互形态

1. **菜单栏轻量浮层（极速捕获与快速打勾）**  
   常驻顶部菜单栏，平时无 Dock 图标，默认 ⌘⇧A 唤起或收起。打开工作台后会出现 Dock 图标。回车添加待办，⌘Return 记入灵感手记（会切到浮层「日记」页），或随手勾选今日条目。

2. **三栏大屏工作台（沉浸规划）**  
   左侧按聚焦 / 看板 / 记录 / 项目 / 标签 / 系统分组；中栏清单与进度环；右侧任务检查器。日历、四象限、安排、灵感手记、附件、搜索、回收站都在同一窗口切 tab。设置在侧栏系统分组；⌘, 仍打开系统 Settings 场景。批量操作出现在项目/标签专属清单，不在「任务」页今日清单。

## 核心能力矩阵

1. **今日任务与习惯（主）**  
   - 侧栏「任务」页（页内标题「今日待办」）同一张清单：习惯带重复符号与火焰徽章（`🔥N`），与临时待办混排。
   - 习惯连击：当前天数与历史最高；非排定日与「今天跳过」桥接，不破连击；当天未打卡不破击。
   - 一层子任务：行内 `2/3` 胶囊与展开勾选；纯文本多行备注，行上显示首行预览。
   - NLP（浮层与工作台「任务」页输入）：时间、优先级（`!p1`~`!p4`，预览为「重要且紧急 / 重要 / 紧急 / 其余」）、第一个 `#标签`、多行备注切分。不解析「明天」等日期词，也不解析项目。「下午3点开会」能抽出时刻，「修复3点问题」不会。
   - 项目/标签页多选：批量改期（今天/明天）、完成、项目、标签、「移到回收站」。
   - 昨天 / 即将：顶部芯片，点开才展开；昨天含未打卡习惯。

2. **多维看板与旁路手记（辅）**  
   - **日历**：月网格未完成计数，临时待办可跨日拖拽改期。
   - **四象限**：宫格是「重要且紧急 / 重要 / 紧急 / 其余」，只列该日未完成项，拖拽改优先级，可按日翻。
   - **轻量安排**：当月未完成临时待办的单日色块，拖到另一天改期，不是多日工期条。
   - **灵感手记**：小巧思、密码备忘和日记的长期记录；三个分类可随时打上或改掉，支持 `#标签` 与关键字自动归类、密码模糊与免明文复制（模糊时不可编辑、不能选图、不显示缩略图）、置顶。
   - **附件、搜索、回收站**：集中看活父项的图；搜标题/习惯名/手记正文；软删后可恢复（父项已删或不在库的附件不能单独恢复）。

## 明确不是什么 (边界声明)

- **不是跟前台软件走的繁重上下文工作台**：可选记下捕获时的前台 App Bundle ID（前台是本应用则不写），不读窗口标题，不索要辅助功能权限。
- **不是屏幕监视或剪贴板监听器**：剪贴板热键仅在按下时单次读取；截屏仅单次静图。
- **不是团队协作或重度甘特**：无成员权限、无前置依赖、无工期拉伸。
- **不是外部日历抓取工具**：不收其它日历的会议。可选把未完成临时待办推到本机「AreaChain」日历并回拉改动；专属日历里事件消失时只解开绑定，不删待办。
- **不是倒计时番茄钟**。
- **不是自建云端平台**：无账号。数据在本机 SwiftData。设置里的 iCloud 开关会写入偏好，但打开也不会改本地库。JSON 备份可导出（含手记标签与置顶）；图片二进制不在备份范围内。
