# 产品定位

AreaChain 是菜单栏上的 **今天待办本**：打开看还要做什么、已经勾完什么。

## 一句话

对外只有「任务」一种东西。常驻会每天再出现，临时是今天这一条；两边都可以到点通知。日记是一句话旁路，不跳页。

## 两块能力

1. **今天的任务（主）**  
   同一张纸上分两段：常驻（每天或仅工作日再出现）和今天的临时。勾完、跳过、改时刻都在这一页。昨天没做完的用「昨天 N」另放，不冲进今天的清单。

2. **突然的日记（辅）**  
   短句，⌘回车记下，仍留在任务页。要翻历史再切到日记页。

## 不是什么

- 不是跟当前软件走的上下文工作台
- 不是 Timing / 屏幕监视 / 剪贴板收藏
- 不是 ChronoNote：不做知识库、长文、协作
- 不是项目管理、标签、四象限、日历产品

以后若接到 ChronoNote，只走本机导出的 `SyncPort` JSON，第一版不上账号、不上云。
