# 产品定位

AreaChain 是专为 macOS 打造的高效个人任务看板与习惯打卡助手：既是菜单栏上随手唤出、支持自然语言输入的轻量便签本，也是支持沉浸规划与批量管理的三栏大屏工作台。数据 100% 存放于本地设备，无广告、无多余依赖，守护用户的纯粹与专注。

## 一句话

对外以「个人任务与习惯养成」为核心。常驻习惯按设定周期重现并追踪连续打卡天数（Streak），临时待办支持多级子任务拆解与长文本备注，两端均支持到点通知。灵感手记是轻量旁路，随时捕获小巧思、安全备忘密码与记录碎碎念，不打断工作心流。

## 双重交互形态

1. **菜单栏轻量浮层（极速捕获与快速打勾）**  
   常驻系统顶部菜单栏（无 Dock 图标占用），支持全局快捷键（默认 ⌘⇧A）瞬间唤起与隐藏。用于捕捉突发灵感、快速回车添加待办、⌘回车记入灵感手记、或随手勾选当前已完成条目。

2. **三栏大屏工作台（沉浸规划与多维管理）**  
   专为大屏深度规划打造：左侧多维导航栏（视图切换、项目树、标签列表及实时未完成待办计数），中栏核心清单与进度仪表，右侧全功能任务检查器抽屉（TaskDetailDrawer），底部浮动批量操作栏（BatchActionBar）。无需在多个孤立窗口间频繁切换。

## 核心能力矩阵

1. **今日任务与习惯（主）**  
   - 同一张今日清单：常驻习惯带重复符号与火焰徽章（`🔥N`），与临时待办混排。
   - 习惯养成体系：智能计算连续打卡天数与历史最高连击，非排定日与主动「今天跳过」自动透明桥接，不破连击。
   - 子任务与备注：复杂待办支持无限拆解为多级子任务（带行内 `2/3` 胶囊进度与展开勾选），支持多行长文本备注记录背景与链接。
   - 自然语言智能解析（NLP）：输入时自动提取中文时间（转换为提醒时刻）、优先级（`!p1`~`!p4`）、标签（`#tag`）并自动切分多行备注。
   - 底部批量操作：多选任务一键批量改期（移至今天/明天）、标记完成、归属项目、设置标签或移入废纸篓。
   - 昨日遗留与即将到来：昨天未完成集中在「昨天 N」区域，支持一键补勾或改期；未来排期聚合为「即将 N」区域展示。

2. **多维独立看板与旁路日记（辅）**  
   - **日历月视图**：直观月网格未完成计数，支持将临时待办跨日拖拽改期。
   - **四象限矩阵**：基于重要/紧急法则的四宫格看板，支持拖拽调整事务优先级。
   - **轻量甘特安排**：当月时间轴可视化，任务横条直观拉伸，习惯精准打点。
   - **灵感手记（随手记）**：捕获突发小巧思、安全密码备忘与碎碎念日记；支持多维标签聚合与 `#标签` 快速语法解析、密码隐私防偷窥虚化与免明文一键复制、图钉置顶及图文附件。
   - **资产与安全**：全局集中附件库、全历史全局搜索、全对象软删除回收站。

## 明确不是什么 (边界声明)

- **不是跟前台软件走的繁重上下文工作台**：可选记下捕获时的前台 App Bundle ID，但不读窗口标题、不索要无障碍辅助权限。
- **不是屏幕监视或剪贴板监听器**：剪贴板热键仅在用户明确按下时单次读取当前内容，不轮询剪贴板；截屏仅单次抓取静态画面。
- **不是外部团队项目协作软件**：不做复杂的团队成员、角色权限、甘特前后置强依赖与资源工时平衡。
- **不是重度外部日历抓取工具**：不从其他系统日历收割外部会议，保持个人专注纯粹性；仅可选单向同步临时待办至本地 AreaChain 专用日历。
- **不是倒计时番茄钟**：专注计时器已彻底剥离，回归纯粹的极速输入、清晰清单与打卡连击体验。
- **不是自建云端平台**：绝不强求云端账号，无隐私泄露风险，所有数据以 SwiftData 存储于用户 Mac 本机，支持随时导出通用 JSON 备份。
