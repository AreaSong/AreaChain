# 产品定位

AreaChain 是菜单栏上的 **今天待办本**：打开看还要做什么、已经勾完什么。

## 一句话

打开先看今天还要做什么、已经勾完什么；想到的回车加上。例行只是明天还会出现的待办。日记是一句话旁路，不跳页。

## 两块能力

1. **今天的待办（主）**  
   今天要做的和今天勾完的都在同一张纸上。例行项是会每天再出现的待办。昨天没做完的用「昨天 N」另放，不冲进今天的清单。

2. **突然的日记（辅）**  
   短句，⌘回车记下，仍留在任务页。要翻历史再切到日记页。

## 不是什么

- 不是跟当前软件走的上下文工作台
- 不是 Timing / 屏幕监视 / 剪贴板收藏
- 不是 ChronoNote：不做知识库、长文、协作
- 不是项目管理、标签、四象限、日历

以后若接到 ChronoNote，只走本机导出的 `SyncPort` JSON，第一版不上账号、不上云。
