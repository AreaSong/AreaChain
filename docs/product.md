# 产品定位

AreaChain 是菜单栏上的 **今天待办本**：打开看还要做什么、已经勾完什么。

## 一句话

对外只有「任务」一种东西。常驻会按你勾的星期再出现，临时是今天这一条；两边都可以到点通知。日记是一句话旁路，不跳页。

## 两块能力

1. **今天的任务（主）**  
   同一张清单：常驻带重复符号，和今天的临时混在一起。勾完、跳过在这一页；常驻的时刻、星期、项目/标签/四象限在设置里配。昨天没做完的用「昨天 N」另放，不冲进今天的清单。底栏 **日历窗** 用月网格看同一批任务，不是另一个主页。项目可以嵌套；四象限是两个开关，另开窗不替换浮层。安排窗只画自己的任务时间。

2. **突然的日记（辅）**  
   短句，⌘回车记下，仍留在任务页。要翻历史再切到日记页。

## 不是什么

- 不是跟当前软件走的上下文工作台（可选记下捕获时的前台 App，不读窗口标题、不要辅助功能）
- 不是 Timing / 屏幕监视 / 剪贴板收藏（第二条热键只读一次剪贴板；截屏只拍当前屏一张）
- 不是 ChronoNote：不做知识库、长文、协作
- 不是项目管理软件：没有成员、多人协作、甘特依赖
- 不是 Calendar.app：不进口别人的会议；可选把临时任务写到名叫 AreaChain 的专用日历

以后若接到 ChronoNote，只走本机导出的 `SyncPort` JSON。身份走 Apple ID / CloudKit，当前签名下本地库照常工作，真双机同步要等开发者账号。
