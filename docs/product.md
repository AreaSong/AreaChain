# 产品定位

AreaChain 是 **Now 层**：住在 macOS 菜单栏，管「今天要做的」和「突然想记下的」。

## 一句话

打开先看今天的任务；想到什么，马上能写成待办或一句日记。

## 两块能力

1. **每天的任务（主）**  
   上面是例行项（每天早上再出现），下面是今天临时写下的待办。主界面只突出今天。昨天没做完的用「昨天 N」另放，不冲进今天的清单。

2. **突然的日记（辅）**  
   短句，一天可以有很多条。和任务分两页。新写下的永远算今天。

## 不是什么

- 不是跟当前软件走的上下文工作台
- 不是 Timing / 屏幕监视 / 剪贴板收藏
- 不是 ChronoNote：不做知识库、长文、协作
- 不是项目管理、标签、四象限

以后若接到 ChronoNote，只走本机导出的 `SyncPort` JSON，第一版不上账号、不上云。
