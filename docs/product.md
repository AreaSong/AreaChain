# 产品定位

AreaChain 是专为 macOS 打造的个人任务看板与习惯打卡助手：菜单栏随手唤出、支持自然语言输入的轻量便签本，加上一扇三栏工作台做规划与批量管理。数据存放于本机，无广告、无账号。

## 一句话

对外以「个人事项」为核心。重复事项是事项的一种属性，按现有星期掩码重现并追踪连续打卡天数（Streak）；一次性事项支持一层子任务与长文本备注。两端均可到点通知。灵感手记是旁路，用来记小巧思、密码备忘和碎碎念。底层仍用 `DailyRoutine` 与 `RoutineCheck` 保存重复属性和历史打卡。没有独立的常驻侧栏入口，重复事项从今日页管理。待处理是一个入口，内部区分逾期和即将，重复事项的状态来自真实排定日，不写入虚假日期。全部事项同时列出未删除的一次性事项和重复事项，子任务仍挂在父事项下。工作台总览提供今日完成、逾期与即将、连击、近 7 日趋势、最近 365 个民事日的贡献热力图，以及最近活动。活动记录是当前数据的派生投影，不是写入磁盘的审计日志；没有完成时间的一次性事项按事项日期显示。系统里的设置只管理偏好和系统集成；隐私与解锁、数据与备份已拆成独立页面。阶段七已把搜索筛选交集、菜单栏与今日/手记筛选共享接到现有规则；浅深色和最小窗口已有 WorkspaceRenderingTests 覆盖；隔离原生走查和阶段八尚未开始。

## 双重交互形态

1. **菜单栏轻量浮层（极速捕获与快速打勾）**

   常驻顶部菜单栏，平时无 Dock 图标，默认 ⌘⇧A 唤起或收起。打开工作台后会出现 Dock 图标。回车添加待办，⌘Return 记入灵感手记（会切到浮层「手记」页），或随手勾选今日条目。

2. **三栏大屏工作台（沉浸规划）**

   左侧按总览 / 事项 / 规划 / 内容 / 组织 / 系统分组。总览是 Dashboard；事项含今日、待处理、全部事项；规划含日历、安排、四象限；内容含灵感手记与附件；组织是平面标签；系统含设置、隐私与解锁、数据与备份、回收站。搜索留在顶部搜索框。中栏清单与进度环；右侧任务检查器。无参数打开工作台进入 Dashboard；明确传入今日、手记或日历的入口仍打开对应页。侧栏系统分组里，设置只含偏好和系统集成，隐私与解锁、数据与备份、回收站各自独立。⌘, 仍打开系统 Settings 场景，内容与侧栏设置相同，不含隐私库和备份。批量操作出现在标签专属清单、待处理和全部事项，不在「今日」页。没有项目。

## 核心能力矩阵

1. **今日任务与习惯（主）**

   - 侧栏「今日」页（页内标题「今日事项」）同一张清单：习惯带重复符号与火焰徽章（`🔥N`），与临时待办混排。
   - 习惯连击：当前天数与历史最高；非排定日与「今天跳过」桥接，不破连击；当天未打卡不破击。
   - 一层子任务：行内 `2/3` 胶囊与展开勾选，拥有独立标签并可搜索；纯文本多行备注，行上显示首行预览。
   - NLP（待办与习惯的新增及标题编辑，含日历、标签页）：时间、优先级（`!p1`~`!p4`，预览为「重要且紧急 / 重要 / 紧急 / 其余」）、多个 `#标签`（正文各行均可识别，保存时复用或创建）、多行备注切分。不解析「明天」等日期词。没有项目。「下午3点开会」能抽出时刻，「修复3点问题」不会。
   - 标签页列出待办、该标签下全部未删除的重复事项（含非今日排定和停用；当天已闭合的进已完成区）和子任务；多选可批量改期（今天/明天，仅待办）、完成、打标签、移除标签、「移到回收站」。组织里的标签管理页负责新建、重命名、排序、颜色、合并、软删除和未使用清理。
   - 昨天 / 即将：顶部芯片，点开才展开；昨天含未打卡习惯。

2. **多维看板与旁路手记（辅）**

   - **日历**：月网格未完成计数。宽、窄布局都能上月、下月和回到今天。临时待办可跨日拖拽改期。
   - **四象限**：宫格是「重要且紧急 / 重要 / 紧急 / 其余」，只列该日未完成项，拖拽改优先级，可按日翻。
   - **轻量安排**：当月未完成临时待办的单日色块，拖到另一天改期，不是多日工期条。
   - **灵感手记**：小巧思、密码备忘和日记的长期记录，支持标签、自动分类和置顶。可按标签启用正文与图片加密；系统验证和独立主密码任选一种或同时启用。移除标签不自动解除已有保护，锁定后不可搜索正文，未保存私密草稿在内存加密封存。
   - **附件、搜索、回收站**：集中看活父项的图；搜任务/子任务/习惯及手记；软删后可恢复（父项已删或不在库的附件不能单独恢复）。

## 明确不是什么 (边界声明)

- **不是跟前台软件走的繁重上下文工作台**：可选记下捕获时的前台 App Bundle ID（前台是本应用则不写），不读窗口标题，不索要辅助功能权限。
- **不是屏幕监视或剪贴板监听器**：剪贴板热键仅在按下时单次读取；截屏仅单次静图。
- **不是团队协作或重度甘特**：无成员权限、无前置依赖、无工期拉伸。
- **不是外部日历抓取工具**：不收其它日历的会议。可选把未完成临时待办推到本机「AreaChain」日历并回拉改动；专属日历里事件消失时只解开绑定，不删待办。
- **不是倒计时番茄钟**。
- **不是自建云端平台**：无账号。数据在本机 SwiftData。设置里的 iCloud 开关只写偏好。普通 JSON 排除私密及旧密码遮罩手记，不含图片二进制；独立口令的加密备份包含记录和图片，可跨私密锁恢复。
- **不是云端密码找回服务**：系统验证依赖本机钥匙串与应用签名；所有解锁凭据及备份口令丢失时不承诺恢复。第一版不做九宫格、每标签独立密码或待办／习惯正文加密。真实数据迁移、应用替换及系统凭据实机验收需受控确认。
