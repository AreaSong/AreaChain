# 产品定位

AreaChain 是菜单栏上的 **今天待办本**：打开看还要做什么、已经勾完什么。

## 一句话

对外只有「任务」一种东西。常驻会按你勾的星期再出现，临时是今天这一条；两边都可以到点通知。日记是一句话旁路，不跳页。

## 两块能力

1. **今天的任务（主）**  
   同一张清单：常驻带重复符号，和今天的临时混在一起。勾完、跳过在这一页；常驻的时刻和开关在设置里配。昨天没做完的用「昨天 N」另放，不冲进今天的清单。底栏 **日历窗** 用月网格看同一批任务，不是另一个主页。

2. **突然的日记（辅）**  
   短句，⌘回车记下，仍留在任务页。要翻历史再切到日记页。

## 不是什么

- 不是跟当前软件走的上下文工作台
- 不是 Timing / 屏幕监视 / 剪贴板收藏
- 不是 ChronoNote：不做知识库、长文、协作
- 不是项目管理、标签、四象限
- 不是 Calendar.app：日历窗只是自己的任务按日铺开，不接系统日历、不做客邀

以后若接到 ChronoNote，只走本机导出的 `SyncPort` JSON，第一版不上账号、不上云。
