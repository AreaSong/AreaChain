# 功能清单

对照当前代码，AreaChain 已实现的能力如下。刻意不做的范围见文末边界声明。

## 1. 壳与工作台架构

| 能力 | 说明 |
|---|---|
| 菜单栏浮层 | 基于 `NSStatusItem` + `NSPopover`，挂在顶部菜单栏，平时无 Dock 图标（`LSUIElement` + `.accessory`）。打开工作台或手记小窗会升为 `.regular`，Dock 会出现；关闭最后一扇后回到 accessory。浮层页签是「**任务 / 手记**」，底栏「工作台」图标按钮直接打开对应页面（悬停提供 Tooltip 说明）；「⋯」提供语法帮助、设置和退出。左侧筛选、中间语法搜索（占位符为「搜索待办与语法...」并享有更大横向呼吸宽度），筛选支持点击、悬停和 ⌘⇧F，在底栏上方打开两级浮层；任务页可选日期、优先级和标签，手记页只有标签，底栏本身保留。已生效条件显示在搜索框里，可单独移除。顶部状态指示器与副标题解耦：任务页按待办状态显示橙点/绿勾/灰勾与「今天还剩 N 项/今日待办已完成/今日无待办」；手记页按手记条数显示印章圆点与「今日手记 N 篇」，空状态显示羽毛笔与温馨引导（彻底消除手记误现孤立橙点）。底栏不再重复显示完成百分比。应用菜单「设置」、**⌘,** 和浮层「设置」打开工作台里的同一套 `SettingsView`。浮层「任务」页与工作台同一套昨天/即将芯片；筛选各自使用浮层和今日过滤条，不共用同一条控件；展开昨天遗留提供未完成计数与「全部延至今日」快捷操作；任务行复选框紧跟标题（保障绝对统一的垂直左对齐线），四象限优先级点移至标题尾部；今日任务全部完成时以紧凑轻量的通透完成标呈现。浮层「手记」页采用严格固定 34pt 单行捕获框（与任务框像素级对齐，消除 Tab 切换跳动与长文本输入时下方列表抖动），长文本横向平滑滚动，包含私密标签时图标动态变为盾牌 🛡，回车或 ⌘Return（或点击「⌘↩」按钮）保存；右侧独立小窗按钮全时段可用（空草稿点击即可新建空白手记小窗）。手记列表支持单击整行高亮选中、双击整行呼出独立大窗口，悬停/选中淡入操作按钮，并打通完整键盘流（↑/↓ 切换选中、Return/⌘O 打开、⌘C 复制、Delete 移入废纸篓、Esc 取消选中）。完整内容可在独立小窗阅读、续写及置顶。 |
| 菜单栏单一状态图标 | 入口固定 24pt 宽，18×18pt 模板图像由系统着色。书本内的小点表示仍有事项，内嵌勾号表示今日已处理完，暂无安排时为普通书本；没有独立数字区，也不显示 `0` 或 `99+`。悬停与无障碍标签提供准确数量，包含今日未完成待办与未打卡习惯，和侧栏口径一致。初次读取前显示普通图标并提示状态暂不可用，读取失败保留上次状态。数量、状态或语言变化都不会改变占位。 |
| 三栏大屏工作台 | `MainSplitWorkspaceView`：左侧 `WorkspaceSidebarView` 按「总览 / 事项 / 规划 / 内容 / 组织 / 系统」分组。总览是 Dashboard；事项是今日、待处理、全部事项；规划是日历、安排、四象限；内容是灵感手记、剪贴板、附件；组织是平面标签入口和各标签；系统是设置、快捷键、隐私与解锁、数据与备份、回收站。搜索留在顶部搜索框，不进侧栏。没有项目树。标签管理页已接通，侧栏会列出各个标签。今日、待处理和全部事项已实现：待处理页内切换逾期与即将，不另开侧栏入口；全部事项同时包含一次性事项和重复事项，子任务仍属于父事项。重复事项没有独立侧栏入口，待处理状态来自真实排定日投影。行上同时保留星期规则和下一次排定日。Dashboard 已接通：今日、近 7 日和热力图共用同一套日统计，只计排定日上的实际完成；跳过、非排定日和停用后的标记不计入完成，也不增加热力图强度。工作台进度环、侧栏今日角标和菜单栏「今天还剩」共用 `DayBoardLogic.todayProgress`（含当天重复事项，跳过视为已闭合）。子任务不另计；逾期和即将复用 `AgendaProjection.pending`。总览点逾期、即将分别打开待处理里的对应通道。总览今日环旁写明跳过不计完成。热力图按完成数分 0 到 4 档；点真实日期打开日历该日，悬停列出最多 8 条已完成标题，其余写成「还有 N 项」。近 7 日趋势的柱子同样打开日历该日。连击和启用中的重复事项数打开今日页的重复事项面板；今日手记数打开灵感手记。近 7 日合计只显示完成数/排定数。活动只投影已有日期字段，最近 30 天最多 12 条，私密手记不生成活动。点活动里的事项会打开日历该日并打开检查器；点创建的手记打开那一篇小窗，记录已不在时打开手记页；点删除打开回收站并选中那一条，已经彻底删除的只打开回收站。这不是持久化审计日志。设置、快捷键、隐私与解锁、数据与备份已拆成独立页面。搜索筛选交集、菜单栏与今日/手记筛选共享已接到现有规则；浅深色和最小窗口已有 WorkspaceRenderingTests 覆盖；2026-09-26 的隔离 QA 全量测试已通过，证据见工程手册。右栏 `TaskDetailDrawer`。 |
| 任务检查器抽屉 | `TaskDetailDrawer`：行内改标题、纯文本多行备注、一层子任务、2×2 四象限选择器（宫格文案是「重要且紧急 / 重要 / 紧急 / 其余」）、提醒快捷点（09:00 / 12:00 / 15:00 / 18:00 / 20:00，再点可取消），检查器还可选任意时刻。待办另有截止时刻，默认空，只在检查器里设；通知和日历仍用提醒时刻。语法补全里「晚上」是 21:00。**仅待办**有排期芯片（今天 / 明天 / 后天 /「选一天…」）；习惯没有改期芯片，用「重复星期」。另有多个标签、图文附件、创建时间与来源 App。习惯抽屉另含连击卡（当前 + 历史最高 + **检查日**状态：已打卡 / 已跳过 / 非计划打卡日 / 习惯已暂停 / 待打卡）和本月打卡月历（点一天只切换检查日）。检查器可在一次性事项和重复事项之间转换。星期掩码不允许一天都不选；标题栏可按**当前检查日**勾选（日历选中日、昨天芯片、方向键换条后的那一天）。**标签专属清单**打开习惯时把检查日接到今天；切到「今日」也会把 leftover 日历日复位到今天。重复事项不再作为侧栏入口。工具栏可显示/隐藏抽屉；备注正在编辑时 `Esc` 先退出输入；**抽屉**标题 `Esc` 回滚草稿，点别处会保存。清单行内改名是回车或勾保存，`Esc` 或叉取消，点别处不会保存。工作台里否则 `Esc` 先关检查器（保留选中），再清列表焦点或多选。浮层没有检查器，`Esc` 只失焦输入或取消列表焦点。关检查器后再点同一条会重新打开。方向键在检查器关闭时只换焦点、不打开检查器；**检查器已打开时会把抽屉换到当前行**，并更新检查日。 |
| 今日进度环 | 工作台「今日事项」用 `DaybookProgressRing` 显示当天一次性事项和重复事项的完成比例，与侧栏今日角标、菜单栏「今天还剩」同一口径。跳过视为已闭合。没有事项时不显示 100%。 |
| 窗口路由 | 工作台仍由 `AppWindows.openWorkspace(tab:)` 在同一窗口切 tab。单条手记由 `DiaryWindows` 打开独立小窗，同一记录只开一扇；可调整大小并选择窗口置顶，收起浮层不关闭。窗口置顶与列表置顶独立，关工作台不隐藏手记小窗。日历、四象限、安排、附件及回收站保持原路由。 |
| 打开即聚焦与草稿记忆 | 任务捕获和浮层手记草稿由同一个 `BoardComposerSession` 持有，类型都是 `BoardComposerDraft`，均在本次运行保留，不落盘。任务只用正文；手记另外保留标签选择，锁定时只封存手记草稿。手记可把草稿转入小窗续写，不预先保存或复制记录。独立小窗显式保存，关闭及应用退出前确认未保存内容；失败保留，外部编辑冲突不静默覆盖。工作台今日页未提交的捕获草稿记在 `WorkspaceNavigation` 上，顶部搜索替换内容区时不清除，回车保存成功后才清空。待处理和全部事项的页内筛选同样保留；离开这两个页面后再进入时，待处理按逾期/即将规则重新打开，全部事项筛选回到默认。今日、手记和菜单栏共用的标签、优先级、提醒和来源会写入偏好，下次打开还在；日期范围和搜索词不写入偏好。 |
| 打卡微动效与沉底体验 | 待办与习惯勾选时提供细腻物理级交互：`ModernCheckbox` 基于贝塞尔路径实时生长绘制对勾（Path Trim 动画），配合微弹性缩放与触控板触感反馈（`DaybookHaptics`）；任务标题 `ModernTaskTitle` 从左至右平滑滑出删除线并柔和渐淡。勾选后进入 **0.4 秒驻留防反悔期**，期间再次点击可秒级原地撤销；0.4 秒后以 `DaybookMotion.collapse` 弹簧平滑折叠沉底收纳进「已完成」折叠区域。顶部 Header「今天还剩 N 项」与习惯连击徽章「🔥 N」支持数字滚轮滚动过渡（`.numericText`），任务全清时状态点平滑变形为勾号。系统「减弱动态效果」（Reduce Motion）开启时自动降级为即时无延迟响应；自动化测试环境下自动直调，保证测试确定性。 |
| 清单键盘导航 | `DayBoardList`：`↑` / `↓` 在未完成待办 → 习惯 →（已展开时）已完成之间移动。日历在月格或周格获得焦点时，方向键换日，回车进入当日清单；清单获得焦点后，方向键、空格和回车与今日页相同，Esc 回到月格或周格。待处理和全部事项在按钮、菜单或文本输入聚焦时不接管方向键和空格；没有选中行时不吞掉空格、回车、删除和 Esc。检查器关闭时方向键不打开它；**已打开时抽屉会跟到当前行**。捕获框为空再按 `↓` 退出输入并选中第一项（不打开检查器）；`Space` 勾选进入统一的 0.4s 动效与防误触沉底队列（检查日跟点选：昨天芯片勾**昨天**，点回今日行勾**今天**），并在沉底后平滑迁移焦点至下一项；`Return` 展开检查器。浮层 Return 会打开工作台「任务」页（退出标签过滤）；工作台里已有检查器回调时不再重开窗口。`Delete` 对待办或习惯弹出「移到回收站？」确认。多选后空格和 Delete 仍只动焦点行；`E` 进入标题就地编辑（Caps Lock 不影响）；备注或抽屉标题正在编辑时 `Esc` 先退出输入（抽屉标题草稿回滚，点别处会保存）；清单行内改名点别处不保存。工作台否则先关检查器，再取消列表焦点回到输入框。监视器只处理本窗口按键，浮层与工作台不会对同一次 Space 各 toggle 一次。工作台 composer 的 ⌘Return 不会记手记，也不会当成回车新建待办；Shift+Enter 支持换行备注。 |
| 跨日零点自动刷新 | 全局 `DayClock`，零点更新「今天」基准、重算角标、重排当天通知。 |

## 2. 捕获与自然语言解析

| 能力 | 说明 |
|---|---|
| 极速捕获输入框 | **浮层「任务」页**：回车记为今天的临时待办，不显示「**添加**」按钮；点「**手记**」或 **⌘Return** 写入灵感手记（解析 `#标签` 并自动打分类），并**切换到浮层手记页**。输入框右侧是「⌘↩」手记按钮，输入时在框下方显示实时解析预览。浮层任务框保持单行，`Shift+Enter` 不插入换行，语法帮助里也没有换行项；多行粘贴会收成一行。**工作台「任务」页** composer 回车添加待办，右侧有「属性」和「添加」，没有「手记」按钮或 ⌘Return；`Shift+Enter` 在工作台输入框里换行写入备注。日历页、标签专属清单和重复事项的新增使用同一套语法；专属清单新待办记到**今天**并带上该标签。 |
| 自然语言智能解析 (`NaturalLanguageParser`) | 待办与习惯的新增和标题编辑统一使用，包含日历、标签页、重复事项管理及抽屉。提取并洗净标题：<br>1. **时间**：`15:30`、`09:30`、`@15:30`、`下午3点半`、`晚上8点`、`上午9点15分`、`中午12点`、`中午12点和…`、`下午3点开会` 等，写入 `remindMinutes`；「修复3点问题」「下午3点问题」这类「点」后直接跟「问题」不解析为时刻；无「上午/下午…」前缀时，「点」后还需空白、标点、`#@!` 或「和/跟/与/在/去/到/给/把/从/向」（如「3点去开会」会抽出 03:00）；<br>2. **优先级**：`!p1`~`!p4`（大小写均可）、`!重要且紧急`、`!重要紧急`、`!紧急重要`、`!重要不紧急`、`!不重要紧急`、`!重要`、`!紧急`；预览胶囊与四象限页同一套文案（`!p1`→「重要且紧急」，`!p2`→「重要」，`!p3`→「紧急」，`!p4`→「其余」）；<br>3. **标签**：收集**各行全部可挂到待办的** `#标签名`，保存时复用或创建；支持多个标签及带空格的 `#"标签名称"`；「密码 / 小巧思 / 日记」不会挂到待办上，`#密码` 也留在标题里（预览胶囊不出现），后面若还有普通标签则挂那个。手记仍会解析 `#密码` 并打分类。侧栏或抽屉新建/重命名待办标签若用这三个名字，会提示并保持表单打开。<br>4. **多行**：首行标题，其余进 `notes`。<br>输入时用胶囊即时预览时间 / 标签 / 优先级。**不解析**「明天 / 后天」等日期词，`dayKey` 由新增入口决定（今日或日历选中日），「明天」会留在标题里。 |
| 底栏语法搜索 | ⌘F 聚焦，跨日期查找待办（含已完成）、子任务、启用习惯和手记。支持关键词、多个 `#标签`、`!p1`～`!p4`、`@15:30` 组合；候选向上展开，↑↓ 先走候选，没有候选时 ↓ 进入结果。结果上回车打开，空格完成待办、子任务或习惯（按命中日），手记没有完成。Tab/Return 补全；只查询，不创建或修改标签。工作台顶部搜索使用同一套候选。当前页签的筛选与查询取交集，日期范围和提醒是否设置会真正参与匹配，不改写用户输入；结果在浮层内显示。任务和子任务点击进入工作台日历并打开检查器，日期用命中的 `dayKey`；手记点击打开独立小窗。Esc 依次关闭候选、清空查询、退出输入，搜索中不触发捕获框的 ⌘Return。菜单栏里改的任务/手记筛选与工作台今日、手记页是同一份内存状态。 |
| 全局快捷呼出 | 侧栏「系统 → 快捷键」里录制，默认不绑定；已经保存过的组合会保留。录上之后，别的应用在前台也能唤起或收起浮层。热键必须含 ⌘ / ⌥ / ⌃ 之一，纯 Shift 无效；与另一项全局热键相同时，刚录下的生效，另一项停用并在快捷键页标明。 |
| 剪贴板一键加今天 | 全局热键，默认不绑定。录上之后单次读取剪贴板：有文字则**整段当标题**（保留原文并识别标签，不解析时间或优先级），同时有图也不挂图；仅图片则建一条待办并挂图片附件；为空不触发。这一热键本身不监听系统剪贴板。 |
| 剪贴板历史 | 应用打开后持续记下复制内容，存在本机 `Application Support/areachain-clipboard`，不进待办、手记、JSON 导出或加密备份。侧栏「内容 → 剪贴板」直接查看，不需要解锁隐私。页头「弹出小窗」或在快捷键页录制后弹出小窗，同一个快捷键再按一次关闭。小窗独立于工作台，关掉工作台仍留在屏幕上，并可置顶。位置可选指针旁边或屏幕中央。回车复制回剪贴板，⌥回车粘贴到前台，⌥⇧回车以纯文本粘贴。置顶分配固定字母，搜索为空时按该字母复制，且不占条数上限。悬停长文本、图片或文件时在列表下方预览。混合搜索是模糊匹配。复制文件时记路径，粘贴写回文件。可按应用、正则和剪贴板类型忽略，也可暂停、跳过下一次、调整检查间隔、默认去掉格式，或在记下复制时播放提示音。菜单栏图标 Option 单击暂停或继续，Option-Shift 单击跳过下一次。隐藏/临时标记、1Password 与 KeeWeb 类型一律不记。直接粘贴到其他应用才需要辅助功能，启动时不申请。 |
| 前台应用戳记 (可选) | 设置「捕获 → 记下当时的 App」开启后，浮层回车、工作台「任务」页输入、剪贴板热键、日历页与标签清单添加待办时记录前台 App 的 Bundle ID；前台是 AreaChain 自己则不写。不读窗口标题。 |

## 3. 重复事项与打卡连击

用户看到的是统一「事项」。重复事项是事项属性，底层仍为 `DailyRoutine` 与 `RoutineCheck`。周期在检查器中改；今日列表打卡与跳过。新建重复事项在今日页，不在设置里，也不新增侧栏入口。管理全部重复事项（含停用）从今日页页头「管理重复事项」进入，复用 `ResidentsPage`。

| 能力 | 说明 |
|---|---|
| 连续打卡与连胜算法 (`HabitStreakLogic`) | 追踪 `currentStreak` 与 `bestStreak`：<br>1. 行上与抽屉火焰徽章 `🔥 N`；抽屉另显示历史最高与**检查日**状态（已打卡 / 已跳过 / 非计划打卡日 / 习惯已暂停 / 待打卡）；<br>2. 非排定日透明桥接，不中断连胜；<br>3. 「今天跳过」视为合理闭合，保留连胜；<br>4. 当天尚未打卡不破击，漏掉**历史排定日**才清零；<br>5. 非排定日若仍打卡，连击 **+1**。 |
| 周期掩码重复 (`WeekdayMask`) | 任意勾选周一至周日；未勾选日不出现在今日列表、不计入角标、不催促通知。停用记下 `pausedOnDayKey`，暂停期间不当漏打，连击保留；再打开时把暂停那几天记成跳过（不含今天）。升级前就停用、没有暂停日的习惯，启用时从最后一次打卡（否则创建日）补跳过。 |
| 勾完与取消打卡 | 勾选记录 `RoutineCheck`；再点取消完成，并清掉跳过标记。 |
| 今天跳过 | 记 `isDone = true && isSkipped = true`，已完成区显示「已跳过」，明日恢复出现。 |
| 到点本机通知 | 可配提醒时刻；未配置则静音。点横幅打开工作台并定位该事项、打开检查器。横幅另有「完成」「10 分钟」「1 小时」；后两项只推迟这一次，不改保存的提醒时刻。今天仍未完成、未跳过且提醒时刻已过的事项，启动或保存提醒后补发一次，同一天同一条不重复补。已完成或已跳过不补。正文仍是固定短句。通知被拒绝后，设置里改为打开系统通知设置，不再重复申请。 |
| 标签 / 四象限分类 | 可打多个平面标签、分配重要/紧急，列表显示分类小点。待办侧标签不含手记三分类。没有项目。 |
| 重复事项面板 (`ResidentsPage`) | 从今日页打开，不是侧栏页。页头「关闭」回到今日。列表、排序、启停和检查器仍走原逻辑。 |
| 详细长文本备注 (`notes`) | 多行纯文本；抽屉可编辑。备注中的 URL 可点开系统浏览器。 |
| 首次启动预置 | 空库首次打开预置「写日报」（工作日）与「复盘」（每日）；英文界面为 Daily log / Review。 |

## 4. 临时待办、子任务与备注

内容输入中的 `#标签` 在提交时创建或复用并关联，支持多个标签、跨行及引号名称。手记新增和编辑都识别标签，正文原样保留；子任务有独立标签，在标签页单独展示和计数，不挂到父任务。搜索不创建标签，标签名保持纯文本。代码、链接、`\#` 保留字面含义。删除文字不自动解绑。

临时待办底层为 `TodoItem`。

| 能力 | 说明 |
|---|---|
| 增删改与就地编辑 | 圆圈只完成/取消当前任务；中间标题与空白单击立即选中、双击就地改名；右侧 ⋯ 只打开菜单。日清单与标签清单支持 Shift 可见范围选择、⌘ 增减选择，普通点击恢复单选；不跨昨天/即将预览分区。删除会弹出「移到回收站？」确认，时间胶囊仍可单击改提醒。 |
| 灵活动态排期 (`dayKey`) | 可移到今天、明天、后天，或点「选一天…」打开日期选择。NLP **不会**因「明天」改 `dayKey`。 |
| 子任务系统 (`SubtaskItem`) | **仅一层**，不是无限多级：<br>1. 每个待办可含若干子任务（排序、标题、完成状态）；<br>2. 行上 `2/3` 胶囊，点击展开内联勾选；<br>3. 抽屉支持回车连续新增、行内改名与单项删除；<br>4. 勾完父任务（含昨天芯片补勾）时级联完成未完成子任务；再取消父任务不撤回这些子任务。父任务进回收站时，当时未删的子任务与附件打上同一软删时间戳；恢复父任务只还原这批，先前单独删掉的不会被救回。<br>5. JSON 快照含全部子任务（含已软删），便于回收站里的父任务往返备份。 |
| 详细长文本备注 (`notes`) | 原生多行文本编辑器，支持标签及显式优先级、提醒语法，不是富文本。行上截取备注第一行作预览。点击保存、⌘Return、失焦或离开页面时提交；输入中保留草稿，不为未完成的标签提前写库；失败保留本次运行的备注草稿并显示「未保存」，可回到原项重试。 |
| 底部浮动批量操作 | 批量栏出现在**标签专属清单、待处理和全部事项**。「今日」页支持范围高亮，但不提供批量操作栏。只选一次性事项时可改期、完成、加减标签和移到回收站。只选重复事项时可加减标签、启用或停用、移到回收站；标签清单里今天排定的可以打今天的卡，待处理逾期通道打最近一个未闭合排定日，不会改成今天。不能把整条重复事项标成永久完成。混合选择只保留两边都支持的动作。保存失败保留选择和筛选。专属清单列出待办、该标签下全部未删除的重复事项（非今日排定和停用也列出，当天已闭合的进已完成区），以及子任务。 |
| 列表智能过滤条 | 工作台「今日」过滤条始终出现，可按标签、来源 App、优先级和提醒筛选；即使没有昨天/即将芯片、筛选尚未生效也挂着。浮层用底栏上方的浮层选择：任务页是日期、优先级和标签，手记页只有标签。两边共用本次运行的筛选状态，但不是同一条控件。从工作台带入的提醒和来源会显示成可移除胶囊，浮层里不能新选这两项。条件作用于今天、昨天与即将列表，也可以清空。手记三分类不进入待办筛选。已完成默认折叠。 |
| 多图附件与截屏 | 待办与习惯行菜单：「附上图片 / 从剪贴板贴图 / 截当前屏」（指针所在显示器，找不到再退回主屏）。待办与习惯抽屉内可选图与粘贴。手记卡片、浮层手记行和小窗可以选图，也可以从剪贴板贴图；私密手记仍先解锁，图片按同一把锁加密。截屏不附到手记，系统截屏权限说明也只写待办和习惯。父项进回收站时，当时还活着的附件一并软删，「附件」页不再显示。父项已删、不在库里、或仍在回收站时，都不能单独恢复附件。行内缩略图，点击看原图。 |
| 昨天未完成与即将待办 | 浮层「任务」页与工作台「任务」页同一套顶部**芯片**：文案是「昨天 / 即将」加数字（默认折叠，点开才展开）。展开后区块标题是「昨天未完成 / 即将」，展示未完成数量，并提供「全部延至今日」快捷按钮一键顺延昨日待办。昨天区含未完成待办与**未打卡习惯**，可补勾；待办可改期到今天，习惯不能改期。点行会打开检查器并记下检查日。同一习惯若昨天未打、今天也该打，点昨天芯片再空格勾**昨天**，点今日行再空格勾**今天**。方向键在今日清单内移动时检查日回到今天。「即将」为未来排期待办。 |

| 私密锁与加密备份 | 系统验证与独立主密码可单独或同时启用，任意一种成功即可；至少保留一种可用方式，凭据撤销失败可追踪重试。AES-GCM 保护正文和附件，主密码派生包装数据密钥；首次转换须先保存、回读验证独立口令的隐私迁移备份。日常加密备份在「数据与备份」，含全部记录及图片，恢复时使用目标私密锁重新加密并合并，不默认全库覆盖。旧明文清理完成前明确提示，不自动删除外部备份或原始图片。 |
| 系统日历同步 (可选) | 只同步专属「AreaChain」日历中的临时待办。使用本机同步基线比较双方变化：单边修改才传播，双方冲突或旧绑定缺基线且不同则保留并提示。设置页对照标题、日期和提醒，没有可对照事件时写明，核对一致后可重试，不提供采用某一侧覆盖。权限被拒时可打开系统日历设置。坏库降级、读失败、基线损坏时禁止写入/清理。按年分片查询并补查绑定 ID，保留全天 GMT 民事日期规则。远端删除只解绑，普通编辑不会重建事件，完成后重新打开可重新发布。仅删除已确认绑定、远端未改的已完成/软删待办事件；未知遗留事件保留。跨系统部分失败明确报错，不假报同步成功。 |
| 登录自启 | `SMAppService.mainApp`，设置「启动 → 登录时打开」。状态为需要批准时开关保持关闭，并提供打开登录项设置的入口。 |

## 8. 明确不做 (边界声明)

1. **不做外部会议收割**：不导入其它日历的会议或活动。
2. **不做番茄钟倒计时**。
3. **剪贴板历史不写成待办**：后台记录只进独立目录。「剪贴板加今天」仍是按下时单次读取，有文字则不挂图。
4. **不做甘特前置依赖与工期拉伸**：只有单日色块拖放到另一天改期。
5. **不做自建云端账户**：数据在本机 SwiftData。设置里的 iCloud 只说明本版本不同步，不再保存无效偏好。
6. **不做 NLP 日期词解析**：输入「明天」不会改 `dayKey`。
7. **不做成套独立功能窗口**：日历、四象限、安排、附件和回收站在工作台内切 tab。单条手记仍由独立小窗打开，同一记录只开一扇。

## 9. 仍按产品边界保留的行为

这些不是未修的 bug，而是当前刻意保持的范围：

- 「今日」页支持范围选择，但不提供批量操作栏。空格和 Delete 也只动焦点行。批量栏只在标签专属清单、待处理和全部事项；圆圈始终只操作当前任务。
- 工作台「任务」页输入框没有 ⌘Return 记手记，手记走浮层「手记」页右侧「⌘↩」或侧栏「灵感手记」。
- 普通 JSON 不含图片二进制；独立口令的加密备份包含图片，二者不可互相替代。
- 「密码 / 小巧思 / 日记」是手记分类，只出现在灵感手记；待办侧栏、过滤条、批量栏和新建任务标签不会列出它们。若某条待办或习惯已经打上，抽屉里仍显示以便去掉。
