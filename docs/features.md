# 功能清单

对照当前代码，已实现如下。

## 壳

| 能力 | 说明 |
|---|---|
| 菜单栏浮层 | `NSStatusItem` + `NSPopover`，无 Dock（`LSUIElement`） |
| 图标与角标 | 书本 +「今」；今天未完成数 > 0 时显示数字 |
| 日记窗口 | 独立小窗摊日记，可在窗口里直接写 |
| 设置窗 | 底栏打开独立窗口；改登录、热键、导入导出，以及这台电脑的语言和外观 |
| 打开即聚焦 | 浮层出现后输入框自动获得焦点 |
| 跨日刷新 | 浮层与角标共用 `DayClock`，零点一起换「今天」 |

## 输入

| 能力 | 说明 |
|---|---|
| 回车 | 加入所选日期的临时待办；输入框左侧可切今天 / 明天 / 自选日，提交后回到今天 |
| ⌘回车 | 写入今天的日记，并切到日记页；不受左侧日期影响 |
| 热键 | 默认 ⌘⇧A 打开 / 收起同一块菜单栏浮层；设置里可改（测试进程里不注册） |

## 例行项

| 能力 | 说明 |
|---|---|
| 每天重现 | 启用且已到开始日的模板，每天出现在上段 |
| 勾完 / 取消 | 当天 `RoutineCheck` |
| 今天跳过 | 当天算闭合，已完成里标「已跳过」；明天仍出现 |
| 浮层第三页 | 任务 / 日记 / 例行。例行页改模板：改名、启用、仅工作日、上/下、删除 |
| 仅工作日 | 周六日不出现、不进角标、不进「昨天未完成」 |
| 首次预置 | 空库第一次打开写入「写日报」（仅工作日）「复盘」 |

## 今天的待办

| 能力 | 说明 |
|---|---|
| 增删改 | 回车添加；点标题改字；右键删除 |
| 指定到某一天 | 输入框选日，或右键放到今天 / 明天 / 选一天；改的是 `dayKey` |
| 即将 | 已排到未来的未完成待办，点「即将 N」展开；不进今天角标 |
| 勾选 | 完成进折叠区 |
| 已完成折叠 | 默认藏起，一行「已完成 N」 |

## 昨天

| 能力 | 说明 |
|---|---|
| 昨天 N | 只统计昨天未完成，不混进今天列表 |
| 展开补勾 | 今天列表不动，下面展开；例行补勾只改昨天 |
| 改到某天 | 仅临时待办：改 `dayKey` 到今天、明天或自选日期 |

## 日记

| 能力 | 说明 |
|---|---|
| 短句列表 | 按时间倒序；点进去可改 |
| 按日往回翻 | 左右键翻到更早的一天，不能翻到未来；新写下的仍记到今天 |
| 删除 | 右键 |

## 数据

| 能力 | 说明 |
|---|---|
| 本机 SwiftData | 库名 `areachain`；打不开时改用内存并提示，不删原文件 |
| 导出 JSON | 设置 → 导出，带稳定 UUID |
| 导入 JSON | 先预览新增/覆盖条数，确认后才按 UUID upsert |
| 手动清库 | 仅内存回退时可见：确认后删除本机库并退出 |
| 登录自启 | `SMAppService.mainApp` |
| 语言 | 默认跟系统；可强制简体中文 / English。待办、日记、例行名称不翻译 |
| 外观 | 默认跟系统；可强制浅色 / 深色。菜单栏「今」两语都保留 |
| 退出 | 仅浮层底栏「退出」；设置/日记窗红点只关窗口 |
