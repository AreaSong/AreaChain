# 功能清单

对照当前代码，已实现如下。

## 壳

| 能力 | 说明 |
|---|---|
| 菜单栏浮层 | `NSStatusItem` + `NSPopover`，无 Dock（`LSUIElement`） |
| 图标与角标 | 书本 +「今」；今天未完成数 > 0 时显示数字 |
| 日记窗口 | 独立小窗摊日记，可在窗口里直接写 |
| 设置窗 | 底栏打开独立窗口；配常驻、项目/标签，以及登录、热键、捕获、通知授权、iCloud 说明、导入导出、这台电脑的语言和外观 |
| 日历窗 | 底栏打开独立窗口；月网格看自己的任务，点一天勾选。可把**临时**任务拖到另一天的格子（改 `dayKey`）。常驻不能拖。浮层仍锁在今天 |
| 打开即聚焦 | 浮层出现后输入框自动获得焦点；未提交的字关掉后再打开还在 |
| 跨日刷新 | 浮层、角标、通知共用 `DayClock`，零点一起换「今天」并重排下一枪通知 |

## 输入

| 能力 | 说明 |
|---|---|
| 回车或「添加」 | 加入今天的临时任务；设置里若打开 App 戳，会记下当时前台 App |
| 「日记」或 ⌘回车 | 写入今天的日记，留在任务页 |
| 打开浮层 | 默认 ⌘⇧A；设置里可改（测试进程里不注册） |
| 剪贴板加今天 | 默认 ⌘⇧V，读一次剪贴板：有字写成今天一条；只有图则标题为「图片」并当附件；空不加。不能和打开浮层撞车 |

## 常驻

底层仍是 `DailyRoutine`。配置在设置里，今天清单只勾选和跳过。

| 能力 | 说明 |
|---|---|
| 每天重现 | 启用且已到开始日的条目，出现在今天的清单里，行上用重复符号标出 |
| 勾完 / 取消 | 当天 `RoutineCheck` |
| 今天跳过 | 当天算闭合，已完成里标「已跳过」；明天仍出现 |
| 选定星期 | 设置里点日、一、二…。没勾的那天不出现、不进角标、不进「昨天未完成」、不排那天的通知 |
| 关掉 / 删除 | 设置里开关或确认后进回收站。关掉的明天起不出现 |
| 加上每天 | 设置 → 常驻；顶栏回车不加常驻 |
| 时刻 | 设置里可选；设了才跟在标题后面。到点发本机通知。没设时刻不响 |
| 项目 / 标签 / 四象限 | 只在设置里改。浮层常驻仍只勾选和今天跳过。行上用两个小点标重要 / 紧急 |
| 首次预置 | 空库第一次打开写入「写日报」（周一到周五）「复盘」（每天） |

## 临时

底层仍是 `TodoItem`。

| 能力 | 说明 |
|---|---|
| 增删改 | 「添加」或回车写入；点标题改字，悬停出铅笔/垃圾桶，确认后进回收站 |
| 指定到某一天 | 「⋯」或右键放到今天 / 明天 / 选一天；改的是 `dayKey` |
| 日历 | 底栏「日历窗」。月格里是当天未完成数；点一天看那天的清单，可加临时、勾选、跳过。临时可拖到另一天。常驻仍去设置里配星期。系统日历同步默认关，只写 AreaChain 专用日历、只出未完成临时任务；设置里能看见权限和上次成败 |
| 即将 | 已排到未来的未完成任务，有才出现「即将 N」；不进今天角标 |
| 勾选 | 完成进「已完成」 |
| 已完成 | 默认展开，点标题可收起 |
| 时刻 | 可选；设了才跟在标题后面。只在那一天那一时刻通知一次 |
| 项目 / 标签 / 四象限 | 行上 ⋯ 可改。清单按 重要且紧急 → 重要 → 紧急 → 其余 排，同档再按时刻、创建时间。底栏「更多 → 四象限」另开一窗，拖进行写两个开关；翻日与日历窗共用。浮层仍是一张清单 |
| 过滤 | 浮层今天清单上方，有项目、标签或 App 戳数据才出现。选某个项目时包含它下面的子孙。日历窗不叠过滤条 |
| 附件 | 行上选图片、从剪贴板贴图，或「截当前屏」拍一张（会要屏幕录制权限，不是一直录）。失败会说明原因。缩略图点开展示。底栏「更多 → 附件」按主人浏览；软删进回收站，彻底删才去文件 |

## 通知

| 能力 | 说明 |
|---|---|
| 本机横幅 | `UNUserNotificationCenter`；菜单栏应用一直挂着即可 |
| 授权 | 第一次设时刻时向系统要；设置里可再请求 |
| 常驻 | 按时刻排下一枪；跳过没勾的星期；今天已勾完 / 已跳过则从下一个勾了的日子算 |
| 临时 | 只在 `dayKey` 那天那一时刻；已勾完或时刻已过则不排 |
| 取消 | 勾完、跳过、关掉、清时刻、改时刻都会先取消再排；标识用条目 UUID |

## 昨天

| 能力 | 说明 |
|---|---|
| 昨天 N | 只统计昨天未完成，不混进今天列表 |
| 展开补勾 | 今天列表不动，下面展开；常驻补勾只改昨天 |
| 改到某天 | 仅临时：改 `dayKey` 到今天、明天或自选日期 |

## 日记

| 能力 | 说明 |
|---|---|
| 短句列表 | 按时间倒序。日记页有输入框和「添加」。点句子可改；悬停出铅笔/垃圾桶，确认后进回收站 |
| 按日往回翻 | 左右键翻到更早的一天，不能翻到未来；新写下的仍记到今天 |
| 附件 | 行上可选图、贴图或截当前屏；缩略图点开展示 |

## 数据

| 能力 | 说明 |
|---|---|
| 本机 SwiftData | 库名 `areachain`；打不开时改用内存并提示，不删原文件 |
| 导出 JSON | 设置 → 导出，带稳定 UUID；含项目/标签/分类字段、项目 `parentID`、临时任务 `calendarEventID`；附件只出元数据。新字段缺省时旧 JSON 仍能读 |
| 导入 JSON | 先预览新增/覆盖条数，确认后才按 UUID upsert |
| iCloud | 设置里有说明开关。当前 ad-hoc 签名没有容器，打开也不改本地库。真同步要等开发者账号 |
| 手动清库 | 仅内存回退时可见：确认后删除本机库和附件目录并退出 |
| 登录自启 | `SMAppService.mainApp` |
| 语言 | 默认跟系统；可强制简体中文 / English。待办、日记、常驻名称不翻译 |
| 外观 | 默认跟系统；可强制浅色 / 深色。菜单栏「今」两语都保留 |
| 回收站 | 底栏打开。可恢复或彻底删除任务、日记、常驻和软删的附件；清空会再确认一次 |
| 退出 | 仅浮层底栏「退出」；各独立窗红点只关窗口 |
| 系统日历 | 设置里默认关。打开后要日历权限，只维护名叫 AreaChain 的日历；勾完或进回收站会删对应事件。不进口其他日历。开关下显示没权限 / 建不了日历 / 上次同步 / 这次没写成。测试进程不碰 EventKit |
| 安排窗 | 底栏「更多 → 安排」。月视图轻量甘特：临时横条可拖，常驻打点 |
| 搜索 | 底栏「更多 → 搜索」。按标题/日记搜所有天；点临时或常驻打开日历窗对应日，点日记打开日记窗那天。浮层仍是今天 |
