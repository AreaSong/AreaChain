# 功能清单

对照当前代码，AreaChain 已实现的能力如下。刻意不做的范围见文末边界声明。

## 1. 壳与工作台架构

| 能力 | 说明 |
|---|---|
| 菜单栏浮层 | 基于 `NSStatusItem` + `NSPopover`，挂在顶部菜单栏，平时无 Dock 图标（`LSUIElement` + `.accessory`）。打开工作台会升为 `.regular`，Dock 会出现；关掉工作台后回到 accessory。浮层页签是「**任务 / 日记**」，底栏「工作台」直接打开对应页面；「⋯」提供语法帮助、设置和退出。左侧筛选、中间语法搜索，筛选支持点击、悬停和 ⌘⇧F，展开后整条底栏原位替换为标签，收起后恢复工具。顶部显示今日剩余数量，底栏不再重复显示完成百分比。macOS **⌘,** 仍打开同一套 `SettingsView`。浮层「任务」页与工作台同一套昨天/即将芯片和过滤条。浮层「日记」页就是灵感手记卡片流（含「存入手记」/⌘Return、分类筛选与搜索，不重复页标题），不是只读列表。 |
| 菜单栏单一状态图标 | 入口固定 24pt 宽，18×18pt 模板图像由系统着色。书本内的小点表示仍有事项，内嵌勾号表示今日已处理完，暂无安排时为普通书本；没有独立数字区，也不显示 `0` 或 `99+`。悬停与无障碍标签提供准确数量，包含今日未完成待办与未打卡习惯，和侧栏口径一致。初次读取前显示普通图标并提示状态暂不可用，读取失败保留上次状态。数量、状态或语言变化都不会改变占位。 |
| 三栏大屏工作台 | `MainSplitWorkspaceView`：左侧 `WorkspaceSidebarView` 按「聚焦 / 看板 / 记录 / 项目 / 标签 / 系统」分组。聚焦是任务、常驻、搜索；项目按树缩进，右键可重命名、新建子项目、改上级、进回收站。点侧栏项目或标签进入专属清单（`WorkspaceFilteredListView`），待办与挂了该分类的习惯都会列出。右栏 `TaskDetailDrawer`。 |
| 任务检查器抽屉 | `TaskDetailDrawer`：行内改标题、纯文本多行备注、一层子任务、2×2 四象限选择器（宫格文案是「重要且紧急 / 重要 / 紧急 / 其余」）、提醒快捷点（09:00 / 12:00 / 15:00 / 18:00 / 20:00，再点可取消）。**仅待办**有排期芯片（今天 / 明天 / 后天 /「选一天…」）；习惯没有改期芯片，用「重复星期」。另有项目与标签、图文附件、创建时间与来源 App。习惯抽屉另含连击卡（当前 + 历史最高 + **检查日**状态：已打卡 / 已跳过 / 非计划打卡日 / 习惯已暂停 / 待打卡）；星期掩码不允许一天都不选；标题栏可按**当前检查日**勾选（日历选中日、昨天芯片、方向键换条后的那一天）。**常驻页与项目/标签专属清单**打开习惯时把检查日接到今天；切到「任务」或「常驻」也会把 leftover 日历日复位到今天。工具栏可显示/隐藏抽屉；备注正在编辑时 `Esc` 先退出输入；**抽屉**标题 `Esc` 回滚草稿，点别处会保存。清单行内改名是回车或勾保存，`Esc` 或叉取消，点别处不会保存。工作台里否则 `Esc` 先关检查器（保留选中），再清列表焦点或多选。浮层没有检查器，`Esc` 只失焦输入或取消列表焦点。关检查器后再点同一条会重新打开。方向键在检查器关闭时只换焦点、不打开检查器；**检查器已打开时会把抽屉换到当前行**，并更新检查日。 |
| 今日进度环 | 工作台「任务」页（页内标题「今日待办」）用 `DaybookProgressRing` 显示临时待办完成比例，**不含习惯**。 |
| 窗口路由 | 公开入口一律 `AppWindows.openWorkspace(tab:)`，在同一工作台窗口内切 tab。已有工作台时 `PanelWindowController.workspace.show()` 只前置，不重建 hosting。日历、灵感手记、四象限、安排、附件、搜索、回收站不再单独弹窗。macOS **⌘,** 仍打开系统 Settings 场景（同一套 `SettingsView`），这是系统约定入口。 |
| 打开即聚焦与草稿记忆 | **仅菜单栏浮层捕获框**：打开后自动聚焦；未提交草稿存在 `CaptureSession.shared.draft`，关浮层再开仍在。工作台窗口关掉再开会保留当前 `@State`（不再每次重挂）。切离侧栏「任务」页后，该页 composer 草稿会丢；工作台「灵感手记」新增草稿切走页签后也会丢。浮层手记新增草稿与分类在本次浮层切页/搜索时保留，关闭浮层后不保留；搜索词在底栏切换时保留，不落盘。 |
| 清单键盘导航 | `DayBoardList`：`↑` / `↓` 在未完成待办 → 习惯 →（已展开时）已完成之间移动（仅绑定了焦点的清单；日历页不吞方向键）。检查器关闭时方向键不打开它；**已打开时抽屉会跟到当前行**。捕获框为空再按 `↓` 退出输入并选中第一项（不打开检查器）；`Space` 勾选并尽量移到下一项（检查日跟点选：昨天芯片勾**昨天**，点回今日行勾**今天**）；`Return` 展开检查器。浮层 Return 会打开工作台「任务」页（退出项目/标签过滤）；工作台里已有检查器回调时不再重开窗口。`Delete` 对待办或习惯弹出「移到回收站？」确认；`E` 进入标题就地编辑（Caps Lock 不影响）；备注或抽屉标题正在编辑时 `Esc` 先退出输入（抽屉标题草稿回滚，点别处会保存）；清单行内改名点别处不保存。工作台否则先关检查器，再取消列表焦点回到输入框。监视器只处理本窗口按键，浮层与工作台不会对同一次 Space 各 toggle 一次。工作台 composer 的 ⌘Return 不会记手记，也不会当成回车新建待办；Shift+Enter 不插入换行。 |
| 跨日零点自动刷新 | 全局 `DayClock`，零点更新「今天」基准、重算角标、重排当天通知。 |

## 2. 捕获与自然语言解析

| 能力 | 说明 |
|---|---|
| 极速捕获输入框 | **浮层「任务」页**：回车或点「**添加**」记为今天的临时待办；点「**日记**」或 **⌘Return** 写入灵感手记（解析 `#标签` 并自动打分类），并**切换到浮层日记页**。浮层 `Shift+Enter` 插入换行（多行备注）。**工作台「任务」页** composer 只有回车添加待办，没有「日记」按钮或 ⌘Return。日历页与项目/标签专属清单的添加走纯标题、不跑 NLP；专属清单新待办记到**今天**并带上该项目或标签。 |
| 自然语言智能解析 (`NaturalLanguageParser`) | 浮层、工作台「任务」页新增及清单行内改名使用；抽屉标题仍是纯文本编辑。提取并洗净标题：<br>1. **时间**：`15:30`、`09:30`、`@15:30`、`下午3点半`、`晚上8点`、`上午9点15分`、`中午12点`、`中午12点和…`、`下午3点开会` 等，写入 `remindMinutes`；「修复3点问题」「下午3点问题」这类「点」后直接跟「问题」不解析为时刻；无「上午/下午…」前缀时，「点」后还需空白、标点、`#@!` 或「和/跟/与/在/去/到/给/把/从/向」（如「3点去开会」会抽出 03:00）；<br>2. **优先级**：`!p1`~`!p4`（大小写均可）、`!重要且紧急`、`!重要紧急`、`!紧急重要`、`!重要不紧急`、`!不重要紧急`、`!重要`、`!紧急`；预览胶囊与四象限页同一套文案（`!p1`→「重要且紧急」，`!p2`→「重要」，`!p3`→「紧急」，`!p4`→「其余」）；<br>3. **标签**：只取**第一个可挂到待办的** `#标签名`，匹配已有或新建；「密码 / 小巧思 / 日记」不会挂到待办上，`#密码` 也留在标题里（预览胶囊不出现），后面若还有普通标签则挂那个。手记仍会解析 `#密码` 并打分类。侧栏或抽屉新建/重命名待办标签若用这三个名字，会提示并保持表单打开。<br>4. **多行**：首行标题，其余进 `notes`。<br>输入时用胶囊即时预览时间 / 标签 / 优先级。**不解析**「明天 / 后天」等日期词，也不解析项目名；`dayKey` 固定为今天，「明天」会留在标题里。 |
| 底栏语法搜索 | ⌘F 聚焦，跨日期查找待办（含已完成）、启用习惯和手记。支持关键词、`#标签`、`!p1`～`!p4` 组合；候选向上展开，Tab/Return 补全；不创建标签，不支持 `@时间` 搜索。当前筛选与查询取交集，不改写用户输入；结果在浮层内显示，点击才跳转工作台。Esc 依次关闭候选、清空查询、退出输入，搜索中不触发捕获框的 ⌘Return。 |
| 全局快捷呼出 | 默认 **⌘⇧A** 唤起或收起浮层，可在设置中重录。热键必须含 ⌘ / ⌥ / ⌃ 之一，纯 Shift 无效；粘贴热键不能与唤起热键相同（相同时粘贴热键停用，设置里会标明）。 |
| 剪贴板一键加今天 | 默认 **⌘⇧V** 单次读取剪贴板：有文字则**整段当标题**（不跑 NLP），同时有图也不挂图；仅图片则建一条待办并挂图片附件；为空不触发。不监听系统剪贴板。 |
| 前台应用戳记 (可选) | 设置「捕获 → 记下当时的 App」开启后，浮层回车、工作台「任务」页输入、剪贴板热键、日历页与项目/标签清单添加待办时记录前台 App 的 Bundle ID；前台是 AreaChain 自己则不写。不读窗口标题。 |

## 3. 常驻习惯与打卡连击

常驻习惯底层为 `DailyRoutine`。周期可在聚焦「常驻」页或习惯抽屉中改；主清单打卡与跳过。新建习惯走侧栏聚焦「常驻」，不在设置里。

| 能力 | 说明 |
|---|---|
| 连续打卡与连胜算法 (`HabitStreakLogic`) | 追踪 `currentStreak` 与 `bestStreak`：<br>1. 行上与抽屉火焰徽章 `🔥 N`；抽屉另显示历史最高与**检查日**状态（已打卡 / 已跳过 / 非计划打卡日 / 习惯已暂停 / 待打卡）；<br>2. 非排定日透明桥接，不中断连胜；<br>3. 「今天跳过」视为合理闭合，保留连胜；<br>4. 当天尚未打卡不破击，漏掉**历史排定日**才清零；<br>5. 非排定日若仍打卡，连击 **+1**。 |
| 周期掩码重复 (`WeekdayMask`) | 任意勾选周一至周日；未勾选日不出现在今日列表、不计入角标、不催促通知。停用记下 `pausedOnDayKey`，暂停期间不当漏打，连击保留；再打开时把暂停那几天记成跳过（不含今天）。升级前就停用、没有暂停日的习惯，启用时从最后一次打卡（否则创建日）补跳过。 |
| 勾完与取消打卡 | 勾选记录 `RoutineCheck`；再点取消完成，并清掉跳过标记。 |
| 今天跳过 | 记 `isDone = true && isSkipped = true`，已完成区显示「已跳过」，明日恢复出现。 |
| 到点本机通知 | 可配提醒时刻；未配置则静音。 |
| 项目 / 标签 / 四象限分类 | 可归属项目、打标签、分配重要/紧急，列表显示分类小点。待办侧标签不含手记三分类。 |
| 常驻页 (`ResidentsPage`) | 侧栏聚焦「常驻」列出全部未删习惯（含停用）：新建、改名、启用、星期、提醒；可拖排序。项目/标签/备注/附件走检查器（打开时检查日为今天）。工作台「任务」页标题栏可跳到本页。 |
| 详细长文本备注 (`notes`) | 多行纯文本；抽屉可编辑。备注中的 URL 可点开系统浏览器。 |
| 首次启动预置 | 空库首次打开预置「写日报」（工作日）与「复盘」（每日）；英文界面为 Daily log / Review。 |

## 4. 临时待办、子任务与备注

临时待办底层为 `TodoItem`。

| 能力 | 说明 |
|---|---|
| 增删改与就地编辑 | 圆圈只完成/取消当前任务；中间标题与空白单击立即选中、双击就地改名；右侧 ⋯ 只打开菜单。日清单与项目/标签清单支持 Shift 可见范围选择、⌘ 增减选择，普通点击恢复单选；不跨昨天/即将预览分区。删除会弹出「移到回收站？」确认，时间胶囊仍可单击改提醒。 |
| 灵活动态排期 (`dayKey`) | 可移到今天、明天、后天，或点「选一天…」打开日期选择。NLP **不会**因「明天」改 `dayKey`。 |
| 子任务系统 (`SubtaskItem`) | **仅一层**，不是无限多级：<br>1. 每个待办可含若干子任务（排序、标题、完成状态）；<br>2. 行上 `2/3` 胶囊，点击展开内联勾选；<br>3. 抽屉支持回车连续新增、行内改名与单项删除；<br>4. 勾完父任务（含昨天芯片补勾）时级联完成未完成子任务；父任务进回收站时，当时未删的子任务与附件打上同一软删时间戳；恢复父任务只还原这批，先前单独删掉的不会被救回。<br>5. JSON 快照含全部子任务（含已软删），便于回收站里的父任务往返备份。 |
| 详细长文本备注 (`notes`) | 纯 `TextEditor`，不是富文本。行上截取备注第一行作预览。抽屉内约 450ms 防抖写入，失焦或离开页面时尝试立即保存；失败保留本次运行的备注草稿并显示「未保存」，可回到原项重试。 |
| 底部浮动批量操作 | 批量栏仍只出现在**项目/标签专属清单**（Shift / ⌘ 点击多选，或工具栏全选当前可见任务）。「任务」页支持范围高亮，但不提供批量操作栏。专属清单列出待办，以及挂了该项目/标签的习惯。可批量改期（今天/明天，仅待办）、完成/未完成（待办改完成态，习惯勾/取消今天）、改项目、加减标签、「移到回收站」（有确认）。全选只包含当前可见任务：完成区展开才包含已完成待办；工具栏再点一次退出批量操作，批量栏另有取消选择。 |
| 列表智能过滤条 | 工作台顶部可按项目（含子树）、标签、来源 App 筛选；浮层顶部保留项目与来源，底栏按普通任务标签和「高优」（重要或紧急）筛选。条件作用于今天、昨天与即将列表；活动条件始终可清空，手记三分类不进入待办筛选。已完成默认折叠。 |
| 多图附件与截屏 | 待办与习惯行菜单：「附上图片 / 从剪贴板贴图 / 截当前屏」（指针所在显示器，找不到再退回主屏）。待办与习惯抽屉内可选图与粘贴；手记卡片目前只能选图。父项进回收站时，当时还活着的附件一并软删，「附件」页不再显示。父项已删、不在库里、或仍在回收站时，都不能单独恢复附件。行内缩略图，点击看原图。 |
| 昨天未完成与即将待办 | 浮层「任务」页与工作台「任务」页同一套顶部**芯片**：文案是「昨天 / 即将」加数字（默认折叠，点开才展开）。展开后区块标题是「昨天未完成 / 即将」。昨天区含未完成待办与**未打卡习惯**，可补勾；待办可改期到今天，习惯不能改期。点行会打开检查器并记下检查日。同一习惯若昨天未打、今天也该打，点昨天芯片再空格勾**昨天**，点今日行再空格勾**今天**。方向键在今日清单内移动时检查日回到今天。「即将」为未来排期待办。 |

## 5. 多维看板与视图

以下视图均在三栏工作台侧栏切换，不是独立窗口。

| 视图 | 说明 |
|---|---|
| 日历月视图 (`CalendarPage`) | 月网格显示每日未完成数字（口径同角标：未完成待办 + 未打卡习惯）；点日期看该日常驻与临时任务。选中日可「加到这一天」（纯标题，记到该日，不跑 NLP）。点清单项打开检查器。仅日历页列表 `allowsTodoDrag: true`，可将**临时待办**拖到另一天格子改期（习惯不可拖）。方向键不用于清单导航，以免抢走月网格。 |
| 四象限矩阵 (`QuadrantPage`) | 宫格标题是「重要且紧急 / 重要 / 紧急 / 其余」（副文案分别为立即处理 / 制定规划 / 授权委托 / 顺延简化）；只列出该日**未完成**项，象限间拖拽改优先级。点卡片打开检查器。可按日前后翻，不只「今天」。 |
| 安排甘特图 (`GanttPage`) | 侧栏名「安排」。当月时间线：只显示**未完成**临时任务的**单日**色块，拖放到另一天即改 `dayKey`（不是拉伸工期；模型只有一个 `dayKey`）。点行名打开检查器。常驻习惯在当月适用星期打点（不是完成记录）；点习惯名时，若该习惯**今天也有点**则检查今天，否则检查当月第一个打点日。 |
| 灵感手记 (`DiaryPage`) | 用来长期记下小巧思、密码备忘和日记。打开页面会确保三个分类标签存在：**密码 / 小巧思 / 日记**。<br>1. **分类筛选**：顶部「全部」与三个分类（及其它标签）带计数，再点一次取消筛选；<br>2. **写入时打标**：点选分类药丸，或正文 `#标签`；点「**存入手记**」或 `⌘Return` 保存；<br>3. **关键字自动打标**：含「密码 / password / pwd」→「密码」；含「巧思 / 灵感 / idea」→「小巧思」；含「日记 / diary / journal」→「日记」；<br>4. **成卡后仍可改标**：每张卡片底部可点按开关「密码 / 小巧思 / 日记」，也可 + 追加其它标签；<br>5. **搜索**：匹配正文与标签名；置顶优先、再按 `createdAt` 倒序；<br>6. **密码防偷窥**：打了密码标签或正文含 `#密码` 时默认模糊，可显示明文或免明文复制；遮罩优先于编辑器和附件；重新遮罩时编辑草稿仍保留，离开页面、失去应用焦点或内容/分类变化会恢复遮罩。删除确认、回收站和搜索结果不展示私密正文，附件中心不展示私密手记图片；显式复制仍可用；<br>7. **其它**：图钉置顶、双击编辑、选图、软删。<br>**浮层 ⌘Return**：同样走自动打标与 `#标签` 解析，然后跳到浮层日记页。 |
| 附件中心 (`AttachmentBrowserPage`) | 侧栏名「附件」。按「临时任务 / 日记 / 常驻」聚类缩略图，右键「进回收站」，原图预览。页内提示含习惯。父项已删或不在库里的附件不出现。待办行与待办/习惯抽屉均可选图或粘贴。 |
| 全局搜索 (`SearchPage`) | 跨日期搜索待办标题/备注、习惯名/备注与手记正文，不搜子任务。支持 `#标签` 条件和待办 `!p1`～`!p4` 条件；停用习惯不出现。私密手记可按内容定位，但结果和帮助提示只显示隐藏标题，查看正文需回到手记显式展开。点任务进日历与检查器，点手记滚到对应卡片。 |
| 回收站 (`TrashPage`) | 软删除的任务、习惯、手记、附件、项目与标签（种类文案是「任务 / 常驻 / 日记 / 附件 / 项目 / 标签」）；单项「恢复」或「彻底删除」，顶栏「清空」。父项已删或不在库里的附件不能恢复（按钮说明「请先恢复所属待办、习惯或手记」），只能彻底删除。 |
| 设置中心 (`SettingsView`) | 分区标题依次是：外观（语言：系统 / 中文 / English；外观：系统 / 浅色 / 深色）、启动（「登录时打开」+「打开浮层」+「剪贴板加今天」）、捕获（「记下当时的 App」与截屏说明）、通知、系统日历、iCloud、数据（导出 / 导入 JSON）。iCloud 开关会写入偏好，但 `Persistence` 不读，打开也不改本地库。坏库降级内存库后可「清空本机库并退出」。常驻与项目/标签的增改不在设置里。 |

## 8. 明确不做 (边界声明)

1. **不做外部会议收割**：不导入其它日历的会议或活动。
2. **不做番茄钟倒计时**。
3. **不做后台剪贴板监听**：热键按下时单次读取。
4. **不做甘特前置依赖与工期拉伸**：只有单日色块拖放到另一天改期。
5. **不做自建云端账户**：数据在本机 SwiftData。设置里的 iCloud 开关会写入偏好，但 `Persistence` 不读，打开也不改本地库。
6. **不做 NLP 日期词 / 项目解析**：输入「明天」不会改 `dayKey`。
7. **不做独立功能窗口**：日历、灵感手记等全部在工作台内切 tab。

## 9. 仍按产品边界保留的行为

这些不是未修的 bug，而是当前刻意保持的范围：

- 「任务」页今日清单支持范围选择，但批量操作仍只在项目 / 标签专属清单；圆圈始终只操作当前任务。
- 工作台「任务」页输入框没有 ⌘Return 记手记，手记走浮层「日记」/「存入手记」或侧栏「灵感手记」。
- JSON 备份不含图片二进制。
- 「密码 / 小巧思 / 日记」是手记分类，只出现在灵感手记；待办侧栏、过滤条、批量栏和新建任务标签不会列出它们。若某条待办或习惯已经打上，抽屉里仍显示以便去掉。
