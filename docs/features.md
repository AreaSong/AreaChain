# 功能清单

对照当前代码，AreaChain 完整实现的功能特性如下。

## 1. 壳与工作台架构

| 能力 | 说明 |
|---|---|
| 菜单栏浮层 | 基于 `NSStatusItem` + `NSPopover` 打造，轻量挂载于顶部菜单栏，无 Dock 图标（`LSUIElement` 模式）。 |
| 图标与动态角标 | 菜单栏展示书籍印章图标与「今」字标识；当今日有未完成任务时，实时显示未完成数字角标。 |
| 三栏大屏工作台 | 新增 `MainSplitWorkspaceView`（三栏 macOS 大屏设计）：左侧导航栏（聚合各类视图切换、项目树与标签列表及实时待办计数）、中栏核心清单列表、右栏任务检查器抽屉（`TaskDetailDrawer`）、底部浮动批量操作栏（`BatchActionBar`）。 |
| 任务检查器抽屉 | `TaskDetailDrawer` 提供全面的任务详情审阅与编辑面板：支持行内修改标题、多行详细长备注编辑器、子任务拆解与管理、四象限九宫格矩阵选择器、提醒时刻选择、排定日期修改、项目归属、标签勾选、图文附件与元数据详情。 |
| 今日进度与打卡卡片 | `TodayProgressCard`：显示今日待办与打卡圆形进度环（`DaybookProgressRing`），实时展示达成百分比与「已连续打卡 N 天」火焰徽章提示。 |
| 独立功能窗口系统 | `AppWindows` 统管独立功能窗口：日历窗、灵感手记窗、四象限窗、安排窗（轻量甘特）、附件中心、全局搜索、回收站、设置窗。各窗口支持独立调出，亦可在三栏工作台中一键无缝切换。 |
| 打开即聚焦与草稿记忆 | 浮层或工作台打开后输入框自动获得焦点；未提交的输入文字在关闭浮层后再打开依然完整保留。 |
| 跨日零点自动刷新 | 全局共用 `DayClock` 时钟，零点自动跨日更新「今天」基准，重新计算角标，并重排当天定时通知。 |

## 2. 捕获与自然语言解析

| 能力 | 说明 |
|---|---|
| 极速捕获输入框 | 输入文字后回车直接添加为今日临时任务；点「手记」或按 ⌘回车快速记入灵感手记流，保持在当前页面不跳出。 |
| 自然语言智能解析 (`NaturalLanguageParser`) | 快速输入时自动识别并提取以下结构化要素，并自动洗净任务标题：<br>1. **时间提取**：智能识别中文自然时间与数字时间（如「下午3点半」「15:30」「晚上8点」「中午12点」等），自动转为到点提醒时刻（`remindMinutes`）；<br>2. **优先级提取**：识别 `!p1`~`!p4`、`!重要且紧急`、`!重要`、`!紧急` 等指令，自动设定待办四象限属性；<br>3. **标签提取**：识别 `#标签名`（如 `#工作`、`#健身`），自动匹配已有标签或新建绑定；<br>4. **多行笔记切分**：多行输入时，首行作为待办标题，第二行及后续内容自动存入长文本备注（`notes`）。 |
| 全局快捷呼出 | 默认支持 **⌘⇧A** 全局热键唤起或收起菜单栏浮层，可在设置中按需自定义。 |
| 剪贴板一键加今天 | 默认支持 **⌘⇧V** 全局热键读取一次剪贴板：有文本直接解析写入今日待办；若仅有图片则自动挂为图片附件；不监听系统剪贴板。 |
| 前台应用戳记 (可选) | 设置中开启后，添加待办时自动捕获并记录当前前台应用程序（Bundle ID），便于追溯任务上下文。 |

## 3. 常驻习惯与打卡连击

常驻习惯底层为 `DailyRoutine`，配置与周期维护在设置中或任务抽屉中进行，主清单支持日常打卡与跳过。

| 能力 | 说明 |
|---|---|
| 连续打卡与连胜算法 (`HabitStreakLogic`) | 智能追踪每个习惯的当前连击数（`currentStreak`）与历史最高连击（`bestStreak`）：<br>1. **火焰徽章激励**：行上与抽屉中醒目标记 `🔥 N` 连续打卡天数；<br>2. **智能非排定日桥接**：对未安排打卡的日期（例如按工作日设定的习惯在周六日），自动透明桥接，不中断连胜记录；<br>3. **主动跳过桥接**：对于偶发休假执行「今天跳过」的条目，视为合理闭合，保留连胜纪录；<br>4. **当天宽容计算**：当天尚未打卡时显示进行中状态，保持昨天以前累积的连击数，只有错过已排定的历史日期未完成时才清零。 |
| 周期掩码重复 (`WeekdayMask`) | 自由勾选周一至周日的任意执行组合；未勾选的日子不出现在今日列表、不计入角标、不催促通知。 |
| 勾完与取消打卡 | 点击勾选框即完成今日打卡，记录 `RoutineCheck`；支持再次点击取消打卡。 |
| 今天跳过 | 当日特殊情况可选择「今天跳过」，视为当日完成闭合，在已完成中显示「已跳过」，明日准时恢复出现。 |
| 到点本机通知 | 支持配置提醒时刻，到点由系统通知中心推送本地横幅提醒；未配置时刻则保持静音。 |
| 项目 / 标签 / 四象限分类 | 常驻习惯可归属至特定项目、打上标签、分配四象限重要紧急属性，并在列表中显示分类小点。 |
| 详细长文本备注 (`notes`) | 允许为习惯记录多行执行要领、SOP 流程或复盘心得，抽屉中可实时编辑。 |
| 首次启动预置 | 首次空库打开应用时，自动预置「写日报」（工作日）与「复盘」（每日）两个经典习惯。 |

## 4. 临时待办、子任务与备注

临时待办底层为 `TodoItem`，专为日常偶发、排程与灵活拆解的事务打造。

| 能力 | 说明 |
|---|---|
| 增删改与就地编辑 | 点击标题直接就地编辑，悬停显示操作图标；行内「⋯」菜单或右键提供改名、删改；删除二次确认后移入回收站。 |
| 灵活动态排期 (`dayKey`) | 可随时将任务移动至今天、明天或通过日历挑选任意目标日期（更新 `dayKey`）。 |
| 子任务系统 (`SubtaskItem`) | 完善的待办子任务拆解能力：<br>1. **多级拆解**：每个待办可包含若干独立子任务，拥有专属排序、标题与完成状态；<br>2. **微型胶囊进度**：主列表行上直观显示子任务完成进度胶囊（如 `2/3`），点击即可展开折叠内联子任务列表快速打勾；<br>3. **抽屉深度管理**：检查器抽屉提供子任务专属管理面板，支持回车连续新增、行内改名与单项删除；<br>4. **级联状态联动**：勾选完成父任务时，自动级联将所有未完成子任务一并标记完成；父任务移入回收站时，子任务自动级联软删除；<br>5. **快照导入导出**：JSON 数据交换全面包含子任务完整信息。 |
| 详细长文本备注 (`notes`) | 独立于标题的多行文本空间，便于记录上下文背景、链接与细节；任务行自动截取第一行用于轻量预览；右侧检查器内嵌多行文本编辑器。 |
| 底部浮动批量操作 (`BatchActionBar`) | 在多选任务模式下（点击行选择或通过检查器多选），底部浮现悬浮操作卡：<br>1. 批量改期（移至今天 / 明天）；<br>2. 批量修改完成状态（一键标记完成 / 未完成）；<br>3. 批量归属或变更项目；<br>4. 批量添加或移除标签；<br>5. 批量移入回收站。 |
| 列表智能过滤条 | 今日清单顶部提供项目、标签与 App 来源过滤器；筛选父项目时自动包含其所有子孙项目任务。 |
| 多图附件与截屏 | 每项待办支持添加多张本地图片附件、剪贴板快速粘贴图片，或触发「截当前屏」静图捕获；行内展示缩略图，点击弹出全尺寸大图预览。 |
| 昨天未完成与即将待办 | 昨天若有遗留未完成任务，主列表下方独立展开「昨天 N」区域，支持一键补勾或改期到今天；未来排程任务聚合为「即将 N」区域展示。 |

## 5. 多维看板与独立视图

| 视图 | 说明 |
|---|---|
| 日历月视图 (`CalendarStandaloneView`) | 顶部月历网格显示每日待办未完成数字；点击任意日期查看该日所有常驻与临时任务，支持将临时任务拖拽跨日期投递改期；提供专用 AreaChain 系统日历同步开关与状态展示。 |
| 四象限矩阵 (`QuadrantStandaloneView`) | 基于艾森豪威尔法则的四象限面板（重要紧急、重要不紧急、紧急不重要、不重要不紧急）；支持直接在象限间拖拽调整任务优先级，与主清单实时双向同步。 |
| 安排甘特图 (`GanttStandaloneView`) | 面向当月时间线的轻量甘特视图：临时任务以条状图展现并支持横向拖拽调整工期与排期，常驻习惯在适用日期上精准打点。 |
| 灵感手记 (`DiaryStandaloneView` / `DiaryPage`) | 全功能随手灵感与备忘卡片流：<br>1. **多维标签体系**：小巧思、密码、日记等多维打标分类，顶部滑动标签栏支持一键切换并实时显示各分类手记计数；<br>2. **双通道极速打标**：支持输入框正文直接键入 `#标签` 语法自动提取创建绑定，或通过下方常用标签药丸点选加选/去选；`⌘Return` 极速入库；<br>3. **密码隐私防偷窥**：自动感知密码类内容并默认模糊虚化，支持「👁️ 小眼睛」显隐切换与「📋 复制密码」免明文直接拷贝剪贴板；<br>4. **卡片交互**：支持图钉置顶（Pin）、双击卡片就地编辑正文、标签穿透跳转联动筛选、图文附件与软删除移入回收站。 |
| 附件中心 (`AttachmentBrowserPage`) | 集中式附件资产库：按所属待办、常驻或日记分类展现所有图片缩略图，支持快速软删与原图预览。 |
| 全局搜索 (`SearchPage`) | 支持跨越全部历史与未来日期，模糊检索待办标题、常驻名称与日记正文；点击搜索结果可直接跳转联动至对应日历日或日记页面。 |
| 回收站 (`TrashPage`) | 集中管理所有软删除（`deletedAt != nil`）的任务、习惯、日记和附件；支持单项精准恢复，或彻底粉碎清空。 |
| 设置中心 (`SettingsView`) | 集中管理常驻习惯库、项目树结构与标签、全局热键设定、前台 App 戳记开关、屏幕截图与通知权限、系统日历同步开关、语言切换（中/英）、外观主题（浅色/深色）以及数据导入导出。 |

## 6. 通知系统

| 能力 | 说明 |
|---|---|
| 本机横幅提醒 | 采用 macOS 原生 `UNUserNotificationCenter`，无需后台常驻常驻服务进程，轻量低功耗。 |
| 权限动态申请 | 首次为任务设定提醒时刻时向系统申请通知授权，亦可在设置面板中手动发起授权检测与申请。 |
| 精准智能排程 | 常驻习惯根据设定的生效星期在对应日期排程下一枪通知；临时任务仅在指定 `dayKey` 当天该时刻排程；任务完成或跳过时自动取消排程，避免误报扰民。 |

## 7. 数据持久化与系统集成

| 能力 | 说明 |
|---|---|
| SwiftData 8 张核心表 | 本地数据库名 `areachain`，涵盖 `DailyRoutine`, `RoutineCheck`, `TodoItem`, `SubtaskItem`, `DiaryEntry`（灵感手记，支持多维标签与置顶）, `ProjectItem`, `TagItem`, `AttachmentItem`。 |
| 容灾与安全机制 | 数据库异常打不开时自动降级采用内存数据库运行并明确提示用户，绝不静默破坏或删除用户原库文件。 |
| 全量快照导入与导出 | 设置支持导出完整 JSON 备份（包含稳定的全局 UUID、子任务、长文本备注、项目树父子关联、标签、四象限属性与附件元数据）；导入前提供新增与覆盖数量预览，二次确认后精准更新。 |
| 系统日历同步 (可选) | 可选开启 EventKit 日历集成，专属创建并维护名为「AreaChain」的本地日历，仅单向同步未完成临时任务，不拉取用户私人会议，保证隐私。 |
| 登录自启 | 原生集成 `SMAppService.mainApp`，开机无感平滑启动。 |

## 8. 明确不做 (边界声明)

1. **不做重度外部会议收割**：不导入其他日历的会议或活动为任务，保持今日个人待办与习惯打卡的纯粹性。
2. **不做番茄钟倒计时**：专注计时器已完全剥离，专注于极速输入、清晰清单与习惯连击打卡。
3. **不做后台剪贴板监听**：剪贴板热键仅在用户明确按下时单次读取当前内容，不设立轮询守护监听进程。
4. **不做重度甘特依赖调度**：甘特图仅用于轻量排期预览与拖拽，不做甘特前置依赖链与人力资源平衡。
5. **不做自建云端账户系统**：数据 100% 存放于用户个人 Mac 设备本地，保障最高等级隐私安全。
