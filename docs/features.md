# 功能清单

对照当前代码，AreaChain 已实现的能力如下。刻意不做的范围见文末边界声明。

## 1. 壳与工作台架构

| 能力 | 说明 |
|---|---|
| 菜单栏浮层 | 基于 `NSStatusItem` + `NSPopover`，挂在顶部菜单栏，平时无 Dock 图标（`LSUIElement` + `.accessory`）。打开工作台会升为 `.regular`，Dock 会出现；关掉工作台后回到 accessory。浮层含「待办 / 手记」页签，底栏可打开工作台、显示当前唤起热键、退出应用。 |
| 图标与动态角标 | 菜单栏展示书籍印章与「今」；今日有未完成任务时显示数字（如 `今3`）。角标由 `StatusItemController.refreshCount` 写入。 |
| 三栏大屏工作台 | `MainSplitWorkspaceView`：左侧 `WorkspaceSidebarView` 按「聚焦 / 看板 / 记录 / 项目 / 标签 / 系统」分组；中栏清单；右栏 `TaskDetailDrawer`。点侧栏项目或标签进入专属清单（`WorkspaceFilteredListView`），不是嵌套项目树。 |
| 任务检查器抽屉 | `TaskDetailDrawer`：行内改标题、纯文本多行备注、一层子任务、2×2 四象限选择器、提醒快捷点（09:00 / 12:00 / 15:00 / 18:00 / 20:00，再点可取消）、排期芯片（今天 / 明天 / 后天 / 日历任选）、项目与标签、图文附件、创建时间与来源 App。习惯抽屉另含连击卡（当前 + 历史最高 + 今日状态）与星期掩码（不允许一天都不选）。工具栏可显示/隐藏抽屉；备注正在编辑时 `Esc` 先退出输入；否则 `Esc` 先关检查器（保留选中），再清列表焦点或多选。关检查器后再点同一条会重新打开。 |
| 今日进度环 | 工作台今日页用 `DaybookProgressRing` 显示临时待办完成比例，**不含习惯**。`TodayProgressCard` 组件仍在源码中，当前无调用方。 |
| 窗口路由 | 公开入口一律 `AppWindows.openWorkspace(tab:)`，在同一工作台窗口内切 tab。日历、手记、四象限、甘特、附件、搜索、回收站不再单独弹窗。macOS **⌘,** 仍打开系统 Settings 场景（同一套 `SettingsView`），这是系统约定入口。 |
| 打开即聚焦与草稿记忆 | **仅菜单栏浮层**：打开后捕获框自动聚焦；未提交草稿存在 `CaptureSession.shared.draft`，关浮层再开仍在。工作台 composer 不保证自动聚焦，切离「今日」后 `@State` 草稿会丢。 |
| 清单键盘导航 | `DayBoardList`：`↑` / `↓` 在未完成待办 → 习惯 →（已展开时）已完成之间移动（仅绑定了焦点的清单；日历页不吞方向键）。捕获框为空再按 `↓` 退出输入并选中第一项；`Space` 勾选并尽量移到下一项；`Return` 打开工作台**今日**清单（会退出项目/标签过滤）并展开检查器；`Delete` 对待办或习惯弹出移入回收站确认；`E` 进入标题就地编辑（Caps Lock 不影响）；备注或标题正在编辑时 `Esc` 先退出输入，否则先关检查器，再取消列表焦点回到输入框。监视器只处理本窗口按键，浮层与工作台不会对同一次 Space 各 toggle 一次。 |
| 跨日零点自动刷新 | 全局 `DayClock`，零点更新「今天」基准、重算角标、重排当天通知。 |

## 2. 捕获与自然语言解析

| 能力 | 说明 |
|---|---|
| 极速捕获输入框 | **浮层**：回车添加为今日临时待办；点「手记」或 **⌘Return** 写入灵感手记（解析 `#标签` 并自动打分类），并**切换到浮层手记页**。浮层 `Shift+Enter` 插入换行（多行备注）。**工作台**今日页 composer 只有回车添加待办，没有手记按钮或 ⌘Return。日历页与项目/标签专属清单的添加走纯标题，不跑 NLP。 |
| 自然语言智能解析 (`NaturalLanguageParser`) | 仅浮层与工作台今日 composer 在添加待办时调用。提取并洗净标题：<br>1. **时间**：`15:30`、`09:30`、`@15:30`、`下午3点半`、`晚上8点`、`上午9点15分`、`中午12点` 等，写入 `remindMinutes`；<br>2. **优先级**：`!p1`~`!p4`（大小写均可）、`!重要且紧急`、`!重要紧急`、`!紧急重要`、`!重要不紧急`、`!不重要紧急`、`!重要`、`!紧急`；<br>3. **标签**：只取**第一个** `#标签名`，匹配已有或新建；<br>4. **多行**：首行标题，其余进 `notes`。<br>输入时用胶囊即时预览时间 / 标签 / 优先级。**不解析**「明天 / 后天」等日期词，也不解析项目名；`dayKey` 固定为今天，「明天」会留在标题里。 |
| 全局快捷呼出 | 默认 **⌘⇧A** 唤起或收起浮层，可在设置中重录。热键必须含 ⌘ / ⌥ / ⌃ 之一，纯 Shift 无效；粘贴热键不能与唤起热键相同。 |
| 剪贴板一键加今天 | 默认 **⌘⇧V** 单次读取剪贴板：有文字则**整段当标题**（不跑 NLP）；仅图片则建一条待办并挂图片附件；为空不触发。不监听系统剪贴板。 |
| 前台应用戳记 (可选) | 设置开启后，添加待办时记录当前前台 App 的 Bundle ID。 |

## 3. 常驻习惯与打卡连击

常驻习惯底层为 `DailyRoutine`。周期可在设置或习惯抽屉中改；主清单打卡与跳过。

| 能力 | 说明 |
|---|---|
| 连续打卡与连胜算法 (`HabitStreakLogic`) | 追踪 `currentStreak` 与 `bestStreak`：<br>1. 行上与抽屉火焰徽章 `🔥 N`；抽屉另显示历史最高与今日状态（完成 / 跳过 / 非排定日 / 暂停）；<br>2. 非排定日透明桥接，不中断连胜；<br>3. 「今天跳过」视为合理闭合，保留连胜；<br>4. 当天尚未打卡不破击，漏掉**历史排定日**才清零；<br>5. 非排定日若仍打卡，连击 **+1**。 |
| 周期掩码重复 (`WeekdayMask`) | 任意勾选周一至周日；未勾选日不出现在今日列表、不计入角标、不催促通知。 |
| 勾完与取消打卡 | 勾选记录 `RoutineCheck`；再点取消完成，并清掉跳过标记。 |
| 今天跳过 | 记 `isDone = true && isSkipped = true`，已完成区显示「已跳过」，明日恢复出现。 |
| 到点本机通知 | 可配提醒时刻；未配置则静音。 |
| 项目 / 标签 / 四象限分类 | 可归属项目、打标签、分配重要/紧急，列表显示分类小点。 |
| 详细长文本备注 (`notes`) | 多行纯文本；抽屉可编辑。备注中的 URL 可点开系统浏览器。 |
| 首次启动预置 | 空库首次打开预置「写日报」（工作日）与「复盘」（每日）。 |

## 4. 临时待办、子任务与备注

临时待办底层为 `TodoItem`。

| 能力 | 说明 |
|---|---|
| 增删改与就地编辑 | 双击标题就地改名；悬停显示改/删/⋯；行菜单或右键改名、删改；删除二次确认后移入回收站。单击时间胶囊可改提醒。 |
| 灵活动态排期 (`dayKey`) | 可移到今天、明天、后天，或经日历任选日期。NLP **不会**因「明天」改 `dayKey`。 |
| 子任务系统 (`SubtaskItem`) | **仅一层**，不是无限多级：<br>1. 每个待办可含若干子任务（排序、标题、完成状态）；<br>2. 行上 `2/3` 胶囊，点击展开内联勾选；<br>3. 抽屉支持回车连续新增、行内改名与单项删除；<br>4. 勾完父任务（含昨天芯片补勾）时级联完成未完成子任务；父任务进回收站时，当时未删的子任务与附件打上同一软删时间戳；恢复父任务只还原这批，先前单独删掉的不会被救回。<br>5. JSON 快照含全部子任务（含已软删），便于回收站里的父任务往返备份。 |
| 详细长文本备注 (`notes`) | 纯 `TextEditor`，不是富文本。行上截取备注第一行作预览。抽屉内约 450ms 防抖写入，失焦或离开页面时立即落盘。 |
| 底部浮动批量操作 | 批量栏出现在**项目/标签专属清单**（⌘ 点击进入多选，或工具栏全选）。今日主清单只有单选焦点，没有多选入口。专属清单只列出待办、不列出习惯。可批量改期（今天/明天）、完成/未完成、改项目、加减标签、移入回收站（有确认）。 |
| 列表智能过滤条 | 今日清单顶部可按项目（含子树）、标签、捕获来源 App 过滤。列表排序：四象限优先，其次提醒时刻，再 `createdAt`。已完成默认折叠。 |
| 多图附件与截屏 | 待办与习惯行菜单：选图 / 粘贴图 / 截当前屏。待办与习惯抽屉内可选图与粘贴；手记卡片目前只能选图。父项进回收站时，当时还活着的附件一并软删，附件中心不再显示。行内缩略图，点击看原图。 |
| 昨天未完成与即将待办 | 顶部**芯片**（默认折叠，点开才展开）。「昨天 N」含未完成待办与**未打卡习惯**，可补勾或改期到今天；未来排期聚合为「即将 N」。 |

## 5. 多维看板与视图

以下视图均在三栏工作台侧栏切换，不是独立窗口。

| 视图 | 说明 |
|---|---|
| 日历月视图 (`CalendarPage`) | 月网格显示每日未完成数字；点日期看该日常驻与临时任务。点清单项打开检查器。仅日历页列表 `allowsTodoDrag: true`，可将**临时待办**拖到另一天格子改期（习惯不可拖）。方向键不用于清单导航，以免抢走月网格。 |
| 四象限矩阵 (`QuadrantPage`) | 重要紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急；象限间拖拽改优先级。可按日前后翻，不只「今天」。 |
| 安排甘特图 (`GanttPage`) | 当月时间线：临时任务是**单日**色块，拖放到另一天即改 `dayKey`（不是拉伸工期；模型只有一个 `dayKey`）。常驻习惯在适用日期打点。 |
| 灵感手记 (`DiaryPage`) | 用来长期记下小巧思、密码备忘和日记。打开页面会确保三个分类标签存在：**密码 / 小巧思 / 日记**。<br>1. **分类筛选**：顶部「全部」与三个分类（及其它标签）带计数，再点一次取消筛选；<br>2. **写入时打标**：点选分类药丸，或正文 `#标签`；`⌘Return` 保存；<br>3. **关键字自动打标**：含「密码 / password / pwd」→「密码」；含「巧思 / 灵感 / idea」→「小巧思」；含「日记 / diary / journal」→「日记」；<br>4. **成卡后仍可改标**：每张卡片底部可点按开关「密码 / 小巧思 / 日记」，也可 + 追加其它标签；<br>5. **搜索**：匹配正文与标签名；置顶优先、再按 `createdAt` 倒序；<br>6. **密码防偷窥**：打了密码标签或正文含 `#密码` 时默认模糊，可显示明文或免明文复制；<br>7. **其它**：图钉置顶、双击编辑、选图、软删。<br>**浮层 ⌘Return**：同样走自动打标与 `#标签` 解析，然后跳到手记页。 |
| 附件中心 (`AttachmentBrowserPage`) | 按待办 / 手记 / 习惯聚类缩略图，右键软删，原图预览。待办行与待办/习惯抽屉均可选图或粘贴。 |
| 全局搜索 (`SearchPage`) | 跨日期检索**待办标题、习惯名称、手记正文**，不搜 `notes`、子任务、标签。结果按日分组；点待办进工作台日历该日并选中打开检查器（已完成会展开）；点习惯进**下一个排定日**并打开检查器；点日记进手记并滚到那一条（切走搜索/日历等 tab 后高亮会清掉）。 |
| 回收站 (`TrashPage`) | 软删除的任务、习惯、手记、附件、项目与标签；单项恢复或彻底清空。 |
| 设置中心 (`SettingsView`) | 常驻习惯库、项目树与标签（树形与重命名在这里，不在侧栏）、热键、登录自启、前台 App 戳记、截屏与通知权限、系统日历同步、语言（跟系统 / 中 / 英）、外观（跟系统 / 浅 / 深）、JSON 导入导出。iCloud 开关为占位：打开也不会改本地库。坏库降级内存库后可「重置并退出」。 |

## 6. 通知系统

| 能力 | 说明 |
|---|---|
| 本机横幅提醒 | `UNUserNotificationCenter`，无额外后台常驻进程。 |
| 权限动态申请 | 首次为任务设提醒时申请；设置里可手动检测与申请。 |
| 精准智能排程 | 习惯按生效星期排下一枪；临时任务仅在指定 `dayKey` 当天该时刻排程；完成或跳过时取消，避免误报。 |

## 7. 数据持久化与系统集成

| 能力 | 说明 |
|---|---|
| SwiftData 8 张核心表 | 库名 `areachain`：`DailyRoutine`, `RoutineCheck`, `TodoItem`, `SubtaskItem`, `DiaryEntry`（含 `tagIDs`、`isPinned`）, `ProjectItem`, `TagItem`, `AttachmentItem`。 |
| 容灾与安全机制 | 库打不开时降级内存库并提示，不静默删除原库。 |
| 快照导入与导出 | JSON 含 UUID、子任务、备注、项目树、标签、四象限、手记的 `tagIDs` 与置顶、附件**元数据**（不含图片二进制）。旧备份缺这两项时按空标签、未置顶导入。导入前有新增/覆盖预览。 |
| 系统日历同步 (可选) | 专属本地日历「AreaChain」。不收其它日历的会议。对 AreaChain 日历是**推 + 拉**：回写标题、`dayKey`、`remindMinutes`；系统里改成全天会清掉本机时刻，全天事件按 GMT 午夜写入、结束日开区间多一天，回拉 `dayKey` 也用 GMT（避免西半球错一天）。拉取窗口覆盖待办实际日期（不只 ±2 年）。专属日历里事件消失时，只清空 `calendarEventID`，**不删除**待办。无 token 且未绑定待办的残留事件会在下次推送时清掉。 |
| 登录自启 | `SMAppService.mainApp`，设置里开关。 |

## 8. 明确不做 (边界声明)

1. **不做外部会议收割**：不导入其它日历的会议或活动。
2. **不做番茄钟倒计时**。
3. **不做后台剪贴板监听**：热键按下时单次读取。
4. **不做甘特前置依赖与工期拉伸**：只有单日色块拖放到另一天改期。
5. **不做自建云端账户**：数据在本机 SwiftData。设置里的 iCloud 开关是无效占位。
6. **不做 NLP 日期词 / 项目解析**：输入「明天」不会改 `dayKey`。
7. **不做独立功能窗口**：日历、手记等全部在工作台内切 tab。

## 9. 仍按产品边界保留的行为

这些不是未修的 bug，而是当前刻意保持的范围：

- 今日主清单是单选；批量操作在项目 / 标签专属清单。
- 工作台今日输入框没有 ⌘Return 记手记，手记走浮层或手记页。
- JSON 备份不含图片二进制。
- 「密码 / 小巧思 / 日记」是全局标签，待办侧栏也会看到这三个名字。
